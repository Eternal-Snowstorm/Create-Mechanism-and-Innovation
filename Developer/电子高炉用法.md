# CMI 电子高炉 用法说明

> 设计案：Delta
> 
> KubeJS 代码：Deepseek 辅助
> 
> 机器更改：Delta
> 
> 文档整理：Deepseek

## 🧩 机器概述

电子高炉是一台**多用途工业机器**，它同时代理了 5 种原版配方：

| 代理配方 | 产物类型 | 对应输入端口 |
| :--- | :--- | :--- |
| 匠魂熔炼 | 流体 | `input_melting` |
| 电弧炉 | 物品 | `input_arc` |
| Ad Astra 合金 | 物品 | `input_alloying` |
| 焦炉 | 物品 + 流体 | `input_car_kiln` |
| 旋转窑 | 物品 + 流体 | `input_rotary_kiln` |

## 📥 五个物品输入槽位（UI 左侧从上到下）

打开机器 UI 后，你会在左侧看到 **5 个物品输入格**和 **5 个流体输入槽**。它们分别对应不同的配方组：

### 1. 熔炼槽（`input_melting`）
- **放什么**：任何能被匠魂熔炼的物品（金属锭、粉末、矿石等）。
- **出什么**：对应的**熔融流体**。
- **典型用法**：铁粉 → 熔融铁。

### 2. 电弧槽（`input_arc` / `input_alloying`）
- **放什么**：任何电弧炉能处理的物品（矿物、粉末、金属、合金原料等）。
- **出什么**：对应的**物品**（锭、粉、合金等）。
- **附加能力**：这个格子**同时也接受 Ad Astra 合金配方**的输入。如果你不想单独用合金槽，可以把合金原料也放这里。

### 3. 合金槽（`input_alloying`）
- **放什么**：Ad Astra 合金配方需要的原料。
- **出什么**：对应的**合金物品**。
- **为什么单独存在**：Ad Astra 合金配方最多需要 **4 种物品输入**，而每个格子 `slotSize` 是 1，所以需要一个额外格子来分摊不同原料。

### 4. 焦炉槽（`input_car_kiln` / `input_alloying`）
- **放什么**：焦炉配方的输入（木头、煤炭、木炭等）。
- **出什么**：对应的**物品 + 副产杂酚油流体**。
- **附加能力**：同样接受 Ad Astra 合金配方输入。

### 5. 旋转窑槽（`input_rotary_kiln` / `input_alloying`）
- **放什么**：旋转窑配方的输入（木炭、硝石粉等）。
- **出什么**：对应的**物品 + 副产流体**。
- **附加能力**：同样接受 Ad Astra 合金配方输入。

## 📤 输出端口

- **物品输出**：UI 右侧的两个格子，所有物品产物都会汇到这里。
- **流体输出**：UI 右侧的两个流体槽，所有流体产物（包括副产）都会汇到这里。
- **输出不参与隔离**：无论配方从哪个输入端口进来，产物都统一从这几个输出槽位取出，不需要区分。

## ⚡ 能量

电子高炉需要 **FE 能量**才能工作。

- 从机器背面或底部接入 FE 线缆即可。
- 内部缓存：5,000,000 FE。
- 最大输入：160,000 FE/t。
- 配方耗能由具体配方决定（电弧炉、焦炉等各不相同）。

## 💧 五个流体输入槽

- 用于**匠魂合金配方**（输入多种熔融金属，输出一种新合金）。
- 也用于需要流体输入的其他配方（如焦炉、旋转窑如果有流体输入需求）。
- 所有流体槽**共享同一批槽位名**，配方会自动匹配。

## 🎯 三种使用方式

**手动玩家**：
- 根据你想做的配方，把原料放进**对应名字的格子**。
- 例如：铁粉放熔炼槽 → 熔融铁；铁粉放电弧槽 → 铁锭。

**半自动物流**：
- 你可以用管道/漏斗单独连到某一个端口，让它**只接受一种配方**的原料。
- 例如：专线送铁粉到熔炼槽，专线送煤炭到焦炉槽。

**全自动工厂**：
- 做**两台电子高炉**：
  - 1 号机只保留 `input_melting` 端口 → 所有输入都走熔炼。
  - 2 号机只保留 `input_arc` 端口 → 所有输入都走电弧炉。
- 这样物流系统不用做复杂判断，两台机器各司其职。

## ⚠️ 常见问题

**Q：为什么我把铁粉放进某个格子没反应？**  
A：检查那个格子的名字是否包含该配方需要的槽位名。铁粉走熔炼需要 `input_melting`，走电弧需要 `input_arc`。

**Q：为什么两个格子都能放同一种物品？**  
A：因为某些物品可能同时被多个配方接受（如某些矿粉既是电弧炉原料也是匠魂熔炼原料）。这是设计行为，你放哪个格子就走哪个配方。

**Q：合金配方需要 4 种原料，我该怎么放？**  
A：把 4 种原料分别放进任意一个带 `input_alloying` 名字的格子里（电弧、合金、焦炉、旋转窑格子都可以），机器会自动从这些格子里凑齐原料。

**Q：自动化时怎么避免串料？**  
A：用**两台机器**，每台只保留一个配方端口，从物理上彻底隔离。这也是目前 CMI 推荐的方案。

## ⚙️ 如何更改设置？

### 修改某个端口能接受的配方

1. 打开 `ldlib/assets/mbd2/machine/electronic_blast_furnace/input.sm`。
2. 打开物品特性→槽位名称
3. 想让它接受更多配方，就往数组里加一项；想禁用某个配方，就把对应那一项删掉。
4. 一个特性可以挂多个 slotName（比如电弧槽现在挂了 `input_arc` 和 `input_alloying`），意味着这个格子能同时被多种配方匹配。

### 修改 KubeJS 代理脚本绑定的端口

1. 打开 `kubejs/server_scripts/recipes/mod/mbd2/proxy/ElectronicBlastFurnace.js`。
2. 找到对应代理函数，比如匠魂熔炼是 `proxyMelting`：
   ```javascript
   addIngredient(builder, ingredientJson, "input_melting")
   ```
3. 把第三个参数改成你想绑定的槽位名称即可。
4. 改完在游戏里执行 `/kubejs reload server_scripts` 重载，不用重启游戏。

### 增加新的输入端口 （修改 nbt 的方法，不修改的方法暂未补充）

1. 在 `.sm` 文件的 `machineSettings.traitDefinitions` 里复制一份现有的 item_slot trait。
2. 改两个字段：`name`（唯一，比如 `electronic_blast_furnace_input_item_xxx`）和 `slotNames`（新名字，比如 `input_xxx`）。
3. 在 `ui.children` 里复制一个对应的 item_slot UI 元素，改 `id` 和位置。
4. 在 KubeJS 代理脚本里，把对应配方绑到新的 slotName 上。
5. 重载测试。

### 增加新的部件方块（如果需要物理隔离）（修改 nbt 的方法，不修改的方法暂未补充）

1. 复制 `input.sm`，改 `definition.id`（比如 `cmi:ebf_input_xxx_bus`）和 `traitNameFilter`（指向新的 trait name）。
2. 在控制器的 `shape_infos`、`placeholders.holders`、`pattern` 里把新方块加进去。
3. 在游戏里测试结构能否成型。
