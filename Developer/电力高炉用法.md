## 🧩 机器概述

电子高炉是一台**多用途工业机器**，它同时代理了 5 种原版配方：

| 代理配方      | 产物类型    | 对应 slotName       |
| :------------ | :---------- | :------------------ |
| 匠魂熔炼      | 流体        | `input_melting`     |
| 电弧炉        | 物品        | `input_arc`         |
| Ad Astra 合金 | 物品        | `input_alloying`    |
| 焦炉          | 物品 + 流体 | `input_car_kiln`    |
| 旋转窑        | 物品 + 流体 | `input_rotary_kiln` |

> 注意区分两个概念：
> - **slotName**（上面这张表）：给 KubeJS 代理脚本用的配方槽位标签。
> - **特性名**（trait name）：给 MBD2 用的内部标识，格式 `<机器名>_input_item_<索引>`。

## 📥 五个物品输入槽位

UI 左侧从左到右依次是：

| 序号 | 特性名 | slotName | 用途 |
| :--- | :--- | :--- | :--- |
| 0 | `electronic_blast_furnace_input_item_0` | `input_melting` | 匠魂熔炼 |
| 1 | `electronic_blast_furnace_input_item_1` | `input_arc` + `input_alloying` | 电弧炉 / 合金 |
| 2 | `electronic_blast_furnace_input_item_2` | `input_alloying` | 合金（专用） |
| 3 | `electronic_blast_furnace_input_item_3` | `input_car_kiln` + `input_alloying` | 焦炉 / 合金 |
| 4 | `electronic_blast_furnace_input_item_4` | `input_rotary_kiln` + `input_alloying` | 旋转窑 / 合金 |

### 各类槽位说明

**槽位 0（熔炼）**：放匠魂熔炼能处理的物品（金属锭, 粉末, 矿石），出熔融流体。例：铁粉 → 熔融铁。

**槽位 1（电弧 + 合金）**：放电弧炉能处理的物品，出物品。同时接受 Ad Astra 合金原料。

**槽位 2（合金）**：专用于 Ad Astra 合金。因为合金配方最多要 4 种原料，每格 `slotSize` 是 1，所以需要单独一格分摊。

**槽位 3（焦炉 + 合金）**：放焦炉输入（木头, 煤炭, 木炭），出物品 + 副产杂酚油。同时接受合金原料。

**槽位 4（旋转窑 + 合金）**：放旋转窑输入（木炭, 硝石粉等），出物品 + 副产流体。同时接受合金原料。

## 📤 输出端口

- **物品输出**：UI 右侧两个格子，所有物品产物汇到这里。
- **流体输出**：UI 右侧两个流体槽，所有流体产物（含副产）汇到这里。
- **输出不隔离**：无论配方从哪个输入端口进来，产物统一从输出槽取出。

## ⚡ 能量

电子高炉需要 **FE 能量**。

- 从机器背面或底部接入 FE 线缆。
- 内部缓存：5,000,000 FE。
- 最大输入：160,000 FE/t。
- 配方耗能由具体配方决定。

## 💧 五个流体输入槽

- 用于**匠魂合金配方**（输入多种熔融金属，输出新合金）。
- 也用于需要流体输入的其他配方。
- 所有流体槽**共享同一批 slotName**，配方自动匹配。

## 🎯 三种使用方式

**手动玩家**：根据配方把原料放进对应槽位。

**半自动物流**：管道/漏斗单独连到某一端口，让它只接受一种配方。

**全自动工厂**：做两台电子高炉，每台只保留一个输入端口，物理隔离。

## ⚠️ 常见问题

**Q：铁粉放进某个格子没反应？**  
A：检查那个格子的 slotName 是否包含该配方需要的标签。熔炼用 `input_melting`，电弧用 `input_arc`。

**Q：为什么两个格子都能放同一种物品？**  
A：某些物品可能同时被多个配方接受（如矿粉既是电弧炉原料也是匠魂熔炼原料）。设计行为，放哪个格子就走哪个配方。

**Q：合金配方需要 4 种原料，怎么放？**  
A：把 4 种原料分别放进任意一个带 `input_alloying` slotName 的格子（槽位 1, 2, 3, 4 都可以），机器会自动凑齐。

**Q：自动化时怎么避免串料？**  
A：两台机器，每台只保留一个配方端口。

## ⚙️ 如何更改设置？

### 修改某个端口能接受的配方

1. 打开 `ldlib/assets/mbd2/machine/electronic_blast_furnace/input.sm`。
2. 打开物品特性 → 槽位名称。
3. 想加配方就往数组里加一项；想禁用就删掉对应项。
4. 一个特性可以挂多个 slotName（如槽位 1 挂了 `input_arc` 和 `input_alloying`）。

### 修改 KubeJS 代理脚本绑定的端口

1. 打开 `kubejs/server_scripts/recipes/mod/mbd2/proxy/ElectronicBlastFurnace.js`。
2. 找到对应代理函数，比如匠魂熔炼是 `proxyMelting`：
   ```javascript
   addIngredient(builder, ingredientJson, "input_melting")
   ```
3. 把第三个参数改成你想绑定的 slotName。
4. 执行 `/kubejs reload server_scripts` 重载。
