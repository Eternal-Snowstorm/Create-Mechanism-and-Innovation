## RC(ReConstruction) - RC方案

### 石料处理

- 考虑到自然生成的石料种类及数量较多, 且部分石料获取成本较低, 此处可考虑单独引入一种新的石料作为处理流程的基础原料.
- 以下流程以铁为例.

- 设计约束:
  - `铁质构件`的材料成本为 1 锭 + 1~2 粒.
  - `铁质构件`经过`构件催生器`处理后, 平均产出 3.75 个矿石.
  - `构件催生器`的阶段限制为`安山时代`, 因此安山时代之前不引入石料处理流程.
  - 流程起点为`石头`, 终点为`粉碎矿`.
  - 涉及的材料类型包括:
    - 石头
    - 粗矿
    - 粉碎矿(Create)
    - 粒
    - 锭
    - 熔融金属
    - 碎块(热力)
    - 碎块(MEK)
    - 晶体(MEK)
    - 碎片(MEK)
    - 污浊粉(MEK)
    - 纯净浆液
    - 污浊浆液
    - 粉
    - 盐溶液
    - 盐晶体
    - 构件
    - 小块石头(New)
    - 石头碎块(New)
    - 矿晶(New)

#### 安山时代

- 石头 + 石磨 -> 粉碎矿 x0.4
  - 单个构件对应产量: 1.5 粉碎矿

#### 黄铜时代

- 石头 + 激光切割 -> 小块石头 x1.5
- 小块石头 + 杠杆锤 -> 石头碎块
- 石头碎块 + 粉碎 -> 粉碎矿 x0.4
  - 单个构件对应产量: 2.25 粉碎矿

### 热力时代

- 热力与沉浸式工程的处理方式可并行使用.

##### 热力方式

###### 基础处理

- 石头 + 冲压机 -> 小块石头 x2.4
- 小块石头 + 磨粉机 -> 粉碎矿 x0.5, 可获得额外产量
  - 单个构件对应产量: 2.4 + 额外粉碎矿

###### 强化处理

- 石头 + 热解炉 -> 石头碎块 x2.5
- 石头碎块 + 感应炉 -> 粉碎矿 x0.8 + 副产物
  - 单个构件对应产量: 7.5 + 额外粉碎矿

###### 谐振处理

- 石头 + 硝化起爆器 -> 碎块(TE) x2.8
- 碎块(TE) + 结晶器 -> 矿晶
- 矿晶 + 磨粉机 -> 粉碎矿
  - 单个构件对应产量: 10.5 粉碎矿

##### 沉浸式工程方式

- 石头 + 工业挤压机 -> 石头碎块 x2
- 石头碎块 + 粉碎机 -> 粉碎矿
  - 单个构件对应产量: 7.5 粉碎矿

#### 通用阶段

- 此阶段不再对不同处理路线进行细粒度的数值分级, 以降低配方维护和数值平衡的复杂度.
- MEK作为最终阶段, 允许进行较大幅度的产量提升, 作为完整矿石处理链的终端方案.
- 石头 + 富集仓 -> 富集石头
- 富集石头 + 粉碎机 -> 粉碎矿 x3
  - 单个构件对应产量: 11.25 粉碎矿

### 阶段性矿石处理

- 基本规则:
  - 输入为粗矿, 输出为粉或熔融金属.
  - 粉通过熔点系统进一步处理为锭.
  - 矿石处理流程应尽量避免直接产出粒, 否则可能绕过完整的矿石处理链及熔点系统.
  - 对于需要提供中间产物的流程, 可使用矿石碎块等中间材料替代粒.

- 配方调整:
  - 移除`碎块 x4 -> 粉碎矿 x1`的合成配方, 改为反向分解配方.
  - 移除除匠魂外, 所有模组提供的`粗矿 -> 锭`直接冶炼配方.

- 涉及的材料类型:
  - 粗矿
  - 碎块(热力)
  - 矿渣(New)
  - 粉碎矿(Create)
  - 碎块(MEK)
  - 碎片(MEK)
  - 晶体(MEK)
  - 污浊粉(MEK)
  - 粉
  - 粉末(此处指红石粉, 氟石粉等非金属粉末)
  - 粒
  - 锭
  - 金属副产物(例如金矿处理过程中产生的铅)

#### 匠魂

- 粗矿 -> 匠魂炉 -> 粒 x4.5(45 mB)
  - 最终产出: 4.5 粒

#### 机械动力

- 粗矿 -> 石磨 -> 碎块 x2 -> 匠魂炉 -> 粒 x3(30 mB)
  - 最终产出: 6 粒

- 粗矿 -> 石磨 -> 碎块 x2 -> 振动台 -> 矿渣 + 副产矿渣(50%) -> 匠魂炉 -> 粒 x3(30 mB)
  - 最终产出: 6 锭 + 3 粒副产物

- 粗矿 -> 粉碎轮 -> 粉碎矿 x1 -> 鼓风机 -> 碎块 x2 + 粉末副产物(25%) -> 振动台 -> 矿渣 x2 + 副产矿渣(50%) -> 匠魂炉 -> 粒 x3(30 mB)
  - 最终产出: 1 锭 + 3 粒 + 3 粒副产物 + 0.25 粉末副产物

- 粗矿 -> 粉碎轮 -> 粉碎矿 x1 -> 鼓风机 -> 碎块 x2 + 粉末副产物(25%) -> 压缩机 + 蒸汽 -> 矿渣 x3 -> 匠魂炉 -> 粒 x3(30 mB)
  - 最终产出: 1 锭 + 8 粒 + 0.25 粉末副产物

- 粗矿 -> 粉碎轮 -> 粉碎矿 x1 -> 鼓风机 -> 碎块 x2 + 粉末副产物(25%) -> 压缩机 + 蒸汽 -> 矿渣 x3 -> 动力磨砂机 -> 粉(50%) + 粉副产物(25%)
  - 最终产出: 3 锭 + 1.5 锭副产物 + 0.25 粉末副产物

#### 沉浸式工程

- 考虑到沉浸式工程的处理效率及实际游玩体验, 适当提高该路线的最终产出.
- 粗矿 -> 粉碎机 -> 粉碎矿 x2 + 副产粉碎矿 x1 -> 工业挤压机 -> 碎块 x3 -> 电解槽 -> 粉 x1
  - 最终产出: 6 锭 + 3 锭副产物

#### 热力

- 考虑到热力路线的整体处理效率较低, 提高其副产物及最终产出.

- 粗矿 -> 磨粉机 -> 粉碎矿(150%) -> 离心分离机 -> 粉 x2 + 粉副产物 x1 + 粉末副产物 x1
  - 最终产出: 3 锭 + 1.5 锭副产物 + 1.5 粉末副产物

- 粗矿 -> 硝化起爆器 -> 粉碎矿 x1 + 副产粉碎矿 x1 + 粉末副产物 x1 -> 热解炉 -> 粉 x4
  - 最终产出: 4 锭 + 4 锭副产物 + 1 粉末副产物

#### MEK

- 粗矿 -> 精密锯木机 -> 粉碎矿 x2 + 粉碎矿副产物 x1 -> 粉碎机 / 富集仓 -> 粉 x2
  - 最终产出: 4 锭 + 2 锭副产物

- 粗矿 -> 精密锯木机 -> 粉碎矿 x2 + 粉碎矿副产物 x1 -> 提纯仓 -> 碎块 x2 -> 粉碎机 / 富集仓 -> 粉 x2
  - 最终产出: 8 锭 + 4 锭副产物

- 粗矿 -> 精密锯木机 -> 粉碎矿 x2 + 粉碎矿副产物 x1 -> 化学压射室 -> 碎片 x2 -> 提纯仓 -> 碎块 x2 -> 粉碎机 / 富集仓 -> 粉 x2
  - 最终产出: 16 锭 + 8 锭副产物

- 粗矿 -> 精密锯木机 -> 粉碎矿 x2 + 粉碎矿副产物 x1 -> 化学溶解机 -> 1000 mB -> 化学清洗机 -> 1000 mB -> 化学结晶器 -> 晶体 x2 -> 化学压射室 -> 碎片 x2 -> 提纯仓 -> 碎块 x2 -> 粉碎机 / 富集仓 -> 粉 x2
  - 最终产出: 32 锭 + 16 锭副产物

## ES(EternalSnowstorm) - 中微子方案

### 石料与金属的对应关系

考虑到部分石料在自然环境中的生成量较大, 若直接作为高价值金属的稳定来源, 可能导致玩家在获取少量石料后即可长期维持对应金属的生产.

因此, 各类石料需要通过独立的处理链进行资源转换, 并根据其自然获取难度及对应金属价值调整处理复杂度与最终产出.

- 沙砾 -> 粉碎 -> 沙子
- 沙子 -> 振动处理 -> 石灰粉 + 含杂石英粉 + 金矿碎块(50%)
- 4 金矿碎块 -> 合成 -> 粉碎金矿石

- 安山岩 -> 粉碎 -> 安山岩粉
- 安山岩粉 + 铁 / 锌 -> 安山合金

- 闪长岩 -> 粉碎 -> 闪长岩粉
- 闪长岩粉 + 水 -> 离心处理 -> 纯净沙 + 含杂石英粉 + 石英粉(50%)

- 石灰石 -> 粉碎 -> 石灰粉

- 下界岩 -> 粉碎 -> 余烬面粉
- 余烬面粉 + 牛奶 + 鸡蛋 -> 搅拌 -> 余烬面团
- 余烬面团 -> 工作盆辊压 -> 烈焰蛋糕底
- 注: 鸡蛋可考虑替换为糖. 这样既可以强化甘蔗相关生产链, 也可以避免鸡蛋等随机性较高的资源参与主线流程.

- 皓蓝石 -> 粉碎 -> 粉碎皓蓝石
- 粉碎皓蓝石 + 熔岩 -> 加压处理 -> 熔渣 + 锌矿碎块
- 4 锌矿碎块 -> 合成 -> 粉碎锌矿石

- 辉绿岩 -> 粉碎 -> 粉碎辉绿岩
- 粉碎辉绿岩 + 熔岩 -> 加压处理 -> 熔渣 + 铜矿碎块
- 4 铜矿碎块 -> 合成 -> 粉碎铜矿石

- 绯红岩 -> 粉碎 -> 粉碎绯红岩
- 粉碎绯红岩 + 熔岩 -> 加压处理 -> 熔渣 + 铁矿碎块
- 4 铁矿碎块 -> 合成 -> 粉碎铁矿石

- 赭金沙 -> 粉碎 -> 粉碎赭金沙
- 粉碎赭金沙 + 熔岩 -> 加压处理 -> 熔渣 + 金矿碎块
- 4 金矿碎块 -> 合成 -> 粉碎金矿石

#### 汽鸣铁道

- 花岗岩 -> 粉碎 -> 红沙
- 红沙 + 蒸汽 -> 加压处理 -> 纯净沙 + 含杂石英粉 + 金矿碎块(50%)

- 方解石 -> 粉碎 -> 方解石碎块

- 滴水石块 -> 粉碎 -> 滴水石锥

- 凝灰岩 -> 粉碎 -> 凝灰岩粉
- 凝灰岩粉 + 蒸汽 -> 加压处理 -> 石灰乳(F) + 铅矿碎块 x3
- 4 铅矿碎块 -> 合成 -> 粉碎铅矿石

- 玄武岩 -> 粉碎 -> 玄武岩粉
- 玄武岩粉 + 蒸汽 -> 加压处理 -> 石灰乳(F) + 凝块玄武岩粉
- 凝块玄武岩粉 -> 振动处理 -> 锡矿碎块 + 含杂石英粉

- 深板岩圆石 -> 粉碎 -> 深板岩碎块
- 深板岩碎块 -> 振动处理 -> 燧石 / 深板岩粉
- 深板岩粉 + 蒸汽 -> 加压处理 -> 石灰乳(F) + 镍矿碎块
- 4 镍矿碎块 -> 合成 -> 粉碎镍矿石
