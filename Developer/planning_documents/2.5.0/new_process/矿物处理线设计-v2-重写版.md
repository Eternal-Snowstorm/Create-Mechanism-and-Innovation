**设计原则**：

1. **破碎不产生金属，只产生解离度。** 增产的来源是把前序阶段丢弃的东西回收回来。
2. **阶段差异用四维表达**：流程形态 / 产率 / 纯度 / 渣量。
3. **温度是门槛，不是数值**：每台设备只为卡住 1~2 种关键金属而存在，多余的温度重叠由**配方类型**（还原气氛 / 焙烧 / 精炼 / 造渣 / 合金）区分。
4. **准入是下限，产率是回报**：准入表（第 3 章）规定「最少要做到哪一步」，产率阶梯规定「做得多好拿多少」。两者正交。
5. **准入是「品级要求」，不是「禁令」**：每一层准入都对应一个**已有的产物状态**。
6. **计量锚点**：`90 mB 熔融金属 = 1 锭`（现状 `TConCasting.js:35`），`810 mB = 1 块`，`10 mB = 1 粒`。

### 2.2 设备定位

**感应炉**（`thermal:machine_smelter`）：阶 IV 引入的基础合金设备。合成 = `Casing.THERMAL + Mechanisms.THERMAL.COM + cmi:blaze_unit + create:whisk`（`recipes/device/Thermal.js:111-117`）。现有 15 条 `thermal.smelter` 配方（`recipes/mod/thermal/Smelter.js`）：青铜、黄铜、因瓦、康铜、琥珀金、信号铁、流明、末影锭、龙钢、深渊锭、钛合金、耐火浆、聚合催化合金、沉积催化合金、raw_titanium_mixture。

**红石熔炼炉**（`thermal:machine_furnace`）：与感应炉构成**两级电热合金谱系** —— 感应炉做基础合金、红石熔炼炉做高级合金。两台均为 FE 驱动、不烧燃料。红石熔炼炉定位等同于**「地位上升的熔炉与高炉」**，不需要专属配方：配方类型与熔炉 / 高炉一致（金属料 → 熔融金属），只是温度更高。

**电弧炉**（`immersiveengineering:arc_furnace`）：IE 系设备，现有配方为硅、不锈钢、钢、铝合金、黄铜、玫瑰金（`recipes/material/metal/ArcFurnace.js`），职责是钢铁与不锈钢，不在电热合金谱系内。

**MEK 电力熔炼炉**（`mekanism:energized_smelter`）：材料为不锈钢外壳 + 2× 工业铁板 + 基础构件 + 下界构件 + 烈焰通用构件 + 硅橡胶 200 mB（`recipes/device/Mekanism.js:287-298`），与其它 MEK 机器同级，属阶 V，占 2524 及以上档位。

**车窑淘汰**：车窑（1953）整机删除，其唯一卡点（铬 1907）移交红石熔炼炉（2000）；原「车窑（烈焰血）3094」一档随之取消。

### 2.3 合金归属

**归属完全由熔点决定，不设例外表**：

> **合金熔点 ≤ 设备温度 → 该设备可熔炼。**

合金熔点已由 CMI 金属注册定义，匠魂合金配方直接取用（`recipes/mod/tconstruct/Alloy.js:13,34`）：

```js
this.meltingPoint = CmiMetal.getMetal(material).getMeltingPoint()
tconstruct.alloy(this.resultFluid).temperature(this.meltingPoint)...
```

| 设备 | 温度 | 可熔炼的合金 |
| :-- | --: | :-- |
| 感应炉 | 1500 | 熔点 ≤ 1500（黄铜、青铜、康铜、因瓦…） |
| 红石熔炼炉 | 2000 | 熔点 ≤ 2000 |
| 电弧炉 | 2115 | 熔点 ≤ 2115 |
| MEK 电力熔炼炉 | 2524+ | 熔点 ≤ 2524+ |

分界线取 1500 的依据：不锈钢（1510）落在红石熔炼炉与电弧炉的区间内，**感应炉拦得住它**；因瓦（~1450）等基础合金则能进感应炉。

### 2.4 锇的烈焰血注入

锇（3033）高于红石熔炼炉（2000），单靠炉温无法熔炼。**注入烈焰血 1000 mB 将等效温度上限抬到 3094**，刚好过线。

```
粗锇 ──硝化起爆──▶（掺入铬铜联合处理线）──▶ 锇粉
      ──注入烈焰血 1000 mB──▶ 红石熔炼炉（等效上限 3094）──▶ 锇锭（1 入 → 1 出）
```

烈焰血在此是**助熔介质**而非消耗性原料，代价体现在必须有一条烈焰血供应线。

## 3. 原料准入表

### 3.1 规则

> **金属越晚，能进炉的料就越少。**

除铁、铜、锌、金、锡、铅六种基础金属外，没有任何金属能从粗矿直接烧成成品。

**L3 另有一条流程分界**：**除铝外**，L3 金属的粗矿**必须先经硝化起爆器解离，才能进入粉碎轮** —— 前三个层级的处理线都以粉碎轮开头，只有它们以硝化起爆器开头。

### 3.2 准入表

| 层级 | 金属 | 允许直烧的原料形态 | 必需的前提设备 | 首次可用阶 |
| :-- | :-- | :-- | :-- | :-- |
| **L0 原矿级**（6） | 铁、铜、锌、金、锡、铅 | 矿石 / 粗矿 / 粉碎粗矿 / 粉 / 污浊粉 | 熔化炉（无前置） | 阶 I |
| **L1 破碎级**（6） | 镍、银、钴、钛、阿迪特、埃特恩 | 粉碎粗矿 / 粉 / 污浊粉 | 粉碎轮 | 阶 II |
| **L2 选别级**（3） | 铂、铬、钒 | 精矿 / 焙砂 / 粉 | 振动台 + 鼓风机 + 热解炉 | 阶 III |
| **L3 提取级**（6） | 铝、铀、钨、锇、ostrum、desh | **仅粉**；**除铝外**，粗矿必须先经硝化起爆解离才能粉碎 | **硝化起爆器（前置，阶 IV 解锁）** + 电解机 | 阶 IV ~ V |

各层级对应的产物状态：L0 = 粗矿、L1 = 粉碎粗矿、L2 = 精矿 + 焙砂、L3 = 金属粉。

### 3.3 与产率阶梯的关系

| | 准入表管什么 | 产率阶梯管什么 |
| :-- | :-- | :-- |
| 约束性质 | **下限**：做不到就出不了锭 | **回报**：做得越好，同样粗矿出锭越多 |

L0 金属同样可以从阶 I 一路优化到阶 V（4 锭 → 24 锭）。准入只决定最短的合法路径有多长。

### 3.4 L3 金属的前段路径

**硝化起爆器在阶 IV 解锁。** L3 中**除铝以外**的 5 种金属（铀、钨、锇、ostrum、desh），其粗矿**必须先经硝化起爆器解离才能进入粉碎轮** —— 这是 L3 与前三层级的流程分界：前三个层级都以粉碎轮开头，只有它们以硝化起爆器开头。

```
粗矿 ──硝化起爆器(前置解离)──▶ 解离料 ──粉碎轮──▶ 粉碎粗矿
```

未经硝化的这 5 种粗矿没有粉碎配方。

### 铝：L3 中的例外

**铝不加入硝化起爆前置**。铝土矿属沉积型矿石，无需爆破解离；且**大电解机的制造需要铝**，铝必须更早可得 —— 若把铝推到硝化之后，会形成「电解机需要铝 / 铝需要电解机」的循环。

**铝的解决办法是设备分级**：铝走**小电解机**（阶 III，材料为铁 + 银）出粉，用于制造大电解机。

```
铝土矿 ──粉碎轮──▶ 铝粉碎粗矿 ──振动台+鼓风机──▶ 铝精矿 ──热解炉(焙烧)──▶ 铝焙砂
       ──磨粉机──▶ 矿粉 ──密封处理(+烧碱溶液, 碱浸)──▶ 铝溶液 ──小电解机──▶ 铝粉
       ──熔化炉 937──▶ 铝锭
```

### 其余 5 种：硝化前置后的两条路

**【湿法路】**

```
解离料 ──粉碎轮──▶ 粉碎粗矿 ──振动台+鼓风机──▶ 精矿 ──热解炉(焙烧)──▶ 焙砂
       ──磨粉机──▶ 矿粉(≤75μm) ──密封处理(+酸/碱)──▶ 溶液 ──电解机(电积)──▶ 金属粉(99.9%)
       ──▶ ★熔化炉 / MEK 电力熔炼炉 ──▶ 金属锭
```

**【干法路】（工序更短）**

```
解离料 ──粉碎轮──▶ 粉碎粗矿 ──振动台+鼓风机──▶ 精矿 ──磨粉机──▶ 矿粉
       ──硝化起爆器(再解离)──▶ 金属粉 ──▶ ★熔化炉 / 红石熔炼炉 ──▶ 金属锭
```

**逐金属前段表**：

| 金属 | 粗矿来源 | 硝化前置 | 前段路径 | 制粉设备 | 熔炼设备 | 阶 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| **铝** | 铝土矿 | **不需要** | 粉碎 → 选别 → 焙烧 → 磨粉 → **碱浸**（`cmi:caustic_soda_solution`）→ 铝溶液 | **小电解机** | 熔化炉 937（熔点 660） | IV |
| **铀** | 铀粗矿 | 需要 | 粉碎 → 选别 → 焙烧 → 磨粉 → **酸浸**（`mekanism:sulfuric_acid`）→ 铀溶液 | 电解机 | 熔化炉 > 1132 | IV~V |
| **钨** | 钨粗矿 | 需要 | 粉碎 → 选别 → 焙烧 → 磨粉 → **碱浸** → 结晶机 → 钨酸晶体 → 热解炉 | 电解机 | 熔化炉 + 凛冰燃料 4225 | V |
| **锇** | 锇粗矿 | 需要 | **掺入铬铜联合处理线（第 8.4 节 C′）** | 硝化起爆器 | 红石熔炼炉 + 注入烈焰血（等效 3094） | V |
| **ostrum** | 星球矿石 | 需要 | 粉碎 → 选别 → 精矿 | 硝化起爆器 | 熔化炉 / MEK 电力熔炼炉 | V |
| **desh** | 星球矿石 | 需要 | 粉碎 → 选别 → 精矿 | 硝化起爆器 | 熔化炉 / MEK 电力熔炼炉 | V |

**铝的两性**：氧化铝是两性氧化物，只有强碱能把它从铝硅酸盐中溶出，稀酸浸不动；碳热还原会先得到铝蒸气与碳化铝，因此铝只能走熔盐电解。

### 4.2 造渣剂：二值开关

| 熔炼条件 | 金属回收率 | 落地方式 |
| :-- | --: | :-- |
| 只投精矿 / 焙砂 | 75% | 配方 A |
| **额外投 1 单位造渣剂** | **88%** | 配方 B |

```
铜精矿             → 熔融铜 30 mB   （75%）
铜精矿 + 1 石灰粉   → 熔融铜 40 mB   （88%）
```

- 实现为**两个独立配方**，玩家在 EMI 中选取产率高的那个。
- 造渣剂种类由矿种固定：含酸性脉石（石英质）的矿用**石灰粉**，含碱性脉石（方解石质）的矿用**石英粉**。
- **对纯粉无效**：阶 IV 之后的金属粉已电解提纯，不含脉石。造渣剂因此是阶 II ~ III 的玩法。

## 7. 尾矿处理体系

### 7.1 四个来源

| 编号 | 来源 | 组成 | 品位 |
| :-- | :-- | :-- | :-- |
| T1 | 阶 II 风选尾矿 | 细粒连生体（金属矿物 + 脉石，未解离） | 中（15~25%） |
| T2 | 阶 III 离心尾渣 | 焙烧后铁硅酸盐、残余硫化物 | 低（5~10%） |
| T3 | 阶 IV 浸出渣 | 酸不溶物 + 铅银渣 + 稀贵金属 | 极低品位但高价值 |
| T4 | 阶 V 终渣 | 硅酸盐 + 微量 | 建材级 |

### 7.2 三级再处理

```
T1 ──离心分离机(重选)──▶ 再选精矿 ──回流熔化炉──▶ 金属
   └─ 离心尾渣 ──▶ T2
T2 + T1残渣 ──硝化起爆器──▶ 4 路产物(金属粉/元素/终渣) ──▶ 终渣入 T4
T3 ──密封处理(+酸, 二次浸出)──▶ 二次溶液 ──电解/置换──▶ 稀贵金属 ──▶ 终渣入 T4
T4 ──▶ 建材（液态混凝土 / 耐火砖 / 筑路石）
```

### 7.3 形态：物品

| 尾矿 | 产出设备 | 该设备的流体输出能力 | 尾矿形态 |
| :-- | :-- | :-- | :-- |
| T1 风选尾矿 | 振动台（1入1出）、鼓风机（1入1-4出） | **无** | **必须是物品** |
| T2 离心尾渣 | 离心分离机（1入4物 **1流出**） | 有 | 随 T1 统一为物品 |
| T3 浸出渣 | 密封处理（1物1流入 / 1物1流出） | 有 | 随 T1 统一为物品 |
| T4 终渣 | 硝化起爆器（1入4出） | **无** | **必须是物品** |

**结论**：尾矿统一为物品 `cmi:tailings`（+ 逐金属 `cmi:<m>_tailings`），不引入 `cmi:tailings_slurry`。T1 来自振动台与鼓风机，两台设备都没有流体输出槽位，尾矿从诞生起就必须是物品；中途转流体只会多出一次「物品 → 流体 → 物品」的装卸。物流压力由压缩机（压块）与运输带 / 抽屉解决。

### 7.4 经济性

- 定向回收：`cmi:<m>_tailings` 供定向再处理；通用 `cmi:tailings` 供批量处理。
- 尾矿品位低，处理成本高于直采，尾矿线须全自动才有意义。

### 7.5 逐阶尾矿回收的金属

**回收对象是该批矿石本身的伴生金属** —— 「某一阶段的尾矿能回收出哪些金属」由玩家在此之前处理过哪些矿决定，不由阶段编号决定。

| 阶段 | 尾矿 | 处理方式 | 回收的金属 | 去向 |
| :-- | :-- | :-- | :-- | :-- |
| 阶 II | T1 风选尾矿 | 暂存 | —— | 尾矿池 |
| 阶 III | T1 风选尾矿 | **离心分离机**（重选） | **铁、铜、锌、铅、锡** | 再选精矿 → 熔化炉 |
| 阶 III | T2 离心尾渣 | 暂存 | —— | 尾矿池 |
| 阶 IV | T1 + T2 存量 | **密封处理**（二次**酸浸**） | **铜、锌、镍、钴、银** | 二次溶液 → 电解机 |
| 阶 IV | T3 浸出渣 | **酸浸 + 锌粉置换** | **金、银、铂** | 贵金属粉 → 熔化炉 1092 |
| 阶 V | T1 + T2 全部存量 | **硝化起爆器** | **铁、铜、锌、铅、锡、镍、钴、银、金、铂、钛** | 金属粉 → 熔化炉 / 红石熔炼炉 |

## 8. 金属联合处理系统

### 8.1 定义与四条铁律

**对象**：自然生成较少或不生成的金属。它们不作为独立矿脉开采，而是作为其他金属的副产物产出。

**范式**：把两种（或三种）金属的粗矿**混合投入**同一条联合线，各线**交错推进**（互相消耗对方上一步的副产物），最终同时产出各自主金属与目标副产物。

| # | 铁律 | 含义 |
| --: | :-- | :-- |
| 1 | **两矿混投** | 联合线必须**同时投入**全部参与金属的粗矿，缺一不可 |
| 2 | **交错推进** | 各线**互相消耗对方的上一步副产物**，形成闭环依赖 |
| 3 | **唯一来源** | **目标副产物不在任何其他产线产出** |
| 4 | **同期可玩** | 各线的**解锁阶段必须重叠**，否则先解锁的一方长期空等 |

**共同参数**：

| 项 | 值 |
| :-- | :-- |
| 可用阶 | 阶 IV 起（需要密封处理 + 电解机 + 硫酸） |
| 产率影响 | **不占主线的 4.00 / 6.00 定额**，副产物为额外产出 |
| 尾矿 | 并入第 7.5 节的处理体系 |
| 中间物状态 | 复用产品状态：含铂重砂 = `cmi:platinum_clump`（金属碎块）、阳极泥 = `cmi:platinum_dirty_dust`（污浊粉末） |

### 8.2 A：金 + 银 → 铂

**原料**：金粗矿、银粗矿　　　**目标副产物**：铂

```
【第 1 步 · 并行】
  金粗矿 ──粉碎轮──▶ 金粉碎粗矿
  银粗矿 ──粉碎轮──▶ 银粉碎粗矿

【第 2 步 · 交错一｜银线取用金线】
  银粉碎粗矿 + 金粉碎粗矿（捕集剂）──振动台──▶ 银精矿 + 含铂重砂
  （含铂重砂 = cmi:platinum_clump「金属碎块」）

【第 3 步 · 交错二｜金线取用银线】
  金粉碎粗矿 + 含铂重砂 ──热解炉(焙烧)──▶ 金焙砂 + 铂渣

【第 4 步 · 交错三｜银线取用金线】
  银精矿 + 少量金焙砂 ──密封处理(+硫酸)──▶ 银溶液 + 渣

【第 5 步 · 并行】
  金焙砂 ──密封处理(+硫酸)──▶ 金溶液 ──电解──▶ 金粉（→ 金锭）
  银溶液 ──电解──▶ 银粉（→ 银锭）+ 阳极泥
  （阳极泥 = cmi:platinum_dirty_dust「污浊粉末」）

【第 6 步 · 收口】
  阳极泥 ──精炼（结晶机 / 化学压釜）──▶ 铂粉 ──▶ 铂锭
```

**产物**：金锭 + 银锭 + 铂 + 尾矿

**对应工艺**：第 2 步的捕集剂对应贵金属冶炼的铅试金法与灰吹法；第 6 步的阳极泥对应铜与金银的电解精炼阳极泥。

| 项 | 值 |
| :-- | :-- |
| 前置 | 金线（L0）、银线（L1）各自跑通 |
| 阶段 | 阶 IV |

### 8.3 B′：粗铁 + 蓝宝石（铁-铝）→ 钛

**原料**：粗铁、蓝宝石（Al₂O₃）　　　**目标副产物**：钛（**唯一来源** —— 原蓝宝石单线处理停用）

```
【第 1 步 · 并行】
  粗铁 ──粉碎轮──▶ 铁粉碎粗矿
  蓝宝石 ──粉碎轮──▶ 蓝宝石粉（Al₂O₃）

【第 2 步 · 交错一｜铁线取用蓝宝石线】
  铁粉碎粗矿 + 蓝宝石粉 ──振动台──▶ 铁精矿 + 含钛重砂

【第 3 步 · 交错二｜蓝宝石线取用铁线】
  含钛重砂 + 铁精矿 ──热解炉(焙烧)──▶ 富钛焙砂 + 铁焙砂

【第 4 步 · 并行】
  铁焙砂 ──高炉(1542)──▶ 铁锭 + 含钛炉渣
  蓝宝石粉 ──密封处理(碱浸) + 电解机──▶ 铝粉

【第 5 步 · 交错三｜铁线取用蓝宝石线的铝】
  富钛焙砂 + 含钛炉渣 + 铝粉 ──铝热还原（熔化炉 / 红石熔炼炉 ≥ 2000）──▶ 粗钛 + 氧化铝渣

【第 6 步 · 收口】
  粗钛 ──红石熔炼炉(2000) / 电弧炉(2115)──▶ 钛锭
  氧化铝渣 ──回流蓝宝石线──▶ 循环
```

**产物**：铁锭 + 钛 + 氧化铝渣（回流）+ 尾矿

**对应工艺**：钛铁矿 FeTiO₃ 本身是铁钛氧化物；铝热还原（Al 还原 TiO₂）是制取难熔金属的手段；蓝宝石即 Al₂O₃，同时充当铝源与脉石载体。

| 项 | 值 |
| :-- | :-- |
| 前置 | 高炉（铁线）、密封处理 + 电解机（蓝宝石线） |
| 阶段 | 铁线阶 III、蓝宝石线阶 IV，两条线解锁期重叠 |
| 尾矿 | 铁渣入尾矿池 |

### 8.4 C′：铬 + 铜 + 锇（三线交错）→ 锇粉

**原料**：铬粗矿、铜粗矿、粗锇　　　**目标副产物**：锇（**唯一来源**）

```
【第 1 步 · 并行】
  铬粗矿 ──粉碎轮──▶ 铬粉碎粗矿
  铜粗矿 ──粉碎轮──▶ 铜粉碎粗矿
  粗锇 ──硝化起爆──▶ 锇解离粉（第三股料）

【第 2 步 · 交错一｜铜线取用铬线】
  铜粉碎粗矿 + 铬粉碎粗矿 ──振动台──▶ 铜精矿 + 含锇重砂

【第 3 步 · 交错二｜铬线取用铜线】
  铬粉碎粗矿 + 含锇重砂 ──热解炉(焙烧)──▶ 铬焙砂 + 锇富集渣

【第 4 步 · 交错三｜锇粉在此产生】
  锇解离粉 + 锇富集渣 + 铜精矿 ──密封处理(+烧碱溶液)──▶ 铬溶液 + 铜溶液 + 锇粉

【第 5 步 · 并行】
  铬溶液 ──电解机──▶ 铬粉 ──▶ 铬锭（→ 不锈钢原料）
  铜溶液 ──电解机──▶ 铜粉 ──▶ 铜锭

【第 6 步 · 收口】
  锇粉 + 注入烈焰血 1000 mB ──红石熔炼炉（等效上限 3094）──▶ 锇锭（1 入 → 1 出）
```

**产物**：铬锭 + 铜锭 + 锇锭 + 尾矿

**对应工艺**：锇铱矿天然赋存于铬铁矿；铬铁矿走碱熔氧化路线，对应碱浸。

| 项 | 值 |
| :-- | :-- |
| 前置 | 硝化起爆器、密封处理、电解机、红石熔炼炉 + 烈焰血供应 |
| 阶段 | 铜线阶 I、铬线阶 III~IV、锇线阶 V，定位为**阶 V 终局内容** |
| 尾矿 | 铬渣二次碱浸回收铬、钒 |

### 8.5 阶段对齐

| 联合线 | 各线解锁阶 | 结论 |
| :-- | :-- | :-- |
| **A** 金 + 银 | 金 L0（阶 I）· 银 L1（阶 II~III） | 银略晚，金线可先跑 |
| **B′** 粗铁 + 蓝宝石 | 铁 L0（阶 III 高炉）· 蓝宝石（阶 IV） | 基本同期 |
| **C′** 铬 + 铜 + 锇 | 铬 L2（阶 III~IV）· 铜 L0（阶 I）· 锇 L3（阶 V） | 须等锇线（硝化起爆）到位，定位阶 V 终局 |

### 8.6 实现要点

- 中间物复用产品状态表：含铂重砂 = `cmi:platinum_clump`（金属碎块）、阳极泥 = `cmi:platinum_dirty_dust`（污浊粉末），**无需新增 `MaterialTypes`**；仅 `slurry` / `dirty_slurry` / `crystal` 不可占用。
- 交错在配方层面表现为**附加输入**：银线的振动台配方要求金粉碎粗矿作为附加输入；金线的焙烧配方要求含铂重砂。
- 三条联合线各自作为任务书的独立支线。

## 10. 埃特恩专项设计

| 项 | 设计 |
| :-- | :-- |
| 熔点 | **保持 1486 不上调**。高炉（1542）即可熔融，熔化炉（生物柴油 1636）亦可 |
| 准入层级 | **L1**（粉碎粗矿等级） —— 需要粉碎，但不强制湿法 |
| 技术身份 | 设备数据触点（Mechanism 构件）、导电材料 |
| 核心诉求 | **纯度**（导电材料），而非产量 |
| 路线 | 埃特恩精矿 / 银矿副产 → 硫酸浸出（密封处理）→ 埃特恩溶液 → **小电解机** → 电解埃特恩 → 高炉 / 熔化炉 → 埃特恩锭 |
| 解锁链 | 银（阶 III）→ 小电解机（铁 + 银）→ 硫酸（热解炉）→ 埃特恩电解 |
| 定位 | 全整合包第一条「浸出 → 电积」闭环，阶 IV 大规模湿法的教学关 |
| 卡点方式 | **不用准入卡，用配方要求卡**：数据触点等关键配方要求**电解级埃特恩**（纯度 ≥ 99.9%），直熔得到的粗埃特恩纯度不足 |

埃特恩从银解锁起即参与主线，不绑定任何后期设备；熔点不上调，避免中期涉及数据触点的配方断供。
