## 1. 产物状态

### 1.1 新增状态(5 个)

| 状态         | 载体 | ID                                  | 中文名             | 在流程中的位置                       |
| :----------- | :--- | :---------------------------------- | :----------------- | :----------------------------------- |
| **精矿**     | 物品 | `cmi:<m>_concentrate`               | `<m>精矿`          | 选别(阶 II)的产物，熔炼的直接料      |
| **焙砂**     | 物品 | `cmi:<m>_calcine`                   | `<m>焙砂`          | 焙烧(阶 III)的产物，已脱硫 / 脱碳    |
| **造渣焙砂** | 物品 | `cmi:<m>_fluxed_calcine`            | `造渣<m>焙砂`      | 压缩机加压造渣(阶 III)的产物         |
| **溶液**     | 流体 | `cmi:<m>_solution`                  | `<m>溶液`          | 浸出(阶 III 试点 / 阶 IV 主线)的产物 |
| **尾矿**     | 物品 | `cmi:tailings` / `cmi:<m>_tailings` | `尾矿` / `<m>尾矿` | 全线副产，阶 III / V 的回收对象      |

```js
// Materials.js —— 以铜为例
event.register("copper", MiningLevels.STONE)
    .color(...).isMetal().ingot().plate().nugget().dust().molten()
    .dirty().clump().shard().crystal().slurry().dirtySlurry()
    .type(MaterialTypes.item("concentrate"))    // → cmi:copper_concentrate 「铜精矿」
    .type(MaterialTypes.item("calcine"))        // → cmi:copper_calcine 「铜焙砂」
    .type(MaterialTypes.item("fluxed_calcine")) // → cmi:copper_fluxed_calcine 「造渣铜焙砂」
    .type(MaterialTypes.fluid("solution"))      // → cmi:copper_solution 「铜溶液」
```

- 尾矿为非金属通用物品，单独在 `kubejs/startup_scripts/register/item/Tailings.js`(新建)注册。
- 中文名追加到 `kubejs/client_scripts/lang/zh_cn/Materials.js`。

### 1.2 复用既有状态

`矿物处理线路.md` 产品状态表中，**只有 3 个状态强绑定溶解-结晶线，不可占用**：

| 状态                     | 语义                          | 可用范围          |
| :----------------------- | :---------------------------- | :---------------- |
| `slurry`(浆液)           | 溶解-结晶线中间产物           | **仅溶解-结晶线** |
| `dirty_slurry`(污浊浆液) | 溶解-结晶线中间产物           | **仅溶解-结晶线** |
| `crystal`(晶体)          | 溶解-结晶线产物，用于倍产矿物 | **仅溶解-结晶线** |

**其余状态可在全流程自由使用**：

| 状态                   | 语义                                         | 本设计的用途                                               |
| :--------------------- | :------------------------------------------- | :--------------------------------------------------------- |
| `crushed`(粉碎粗矿)    | 粗矿经粉碎轮的产物                           | 阶 II 主线产物；L1 准入形态                                |
| `dirty_dust`(污浊粉末) | 进一步粉碎的粗矿，含杂质金属粉末或金属化合物 | 阶 II 破碎产物；L0~L3 准入形态之一；**联合处理线的阳极泥** |
| `clump`(金属碎块)      | 大块粗矿碎块                                 | 阶 V-a+ 提纯仓产物；**联合处理线的含铂重砂**               |
| `shard`(金属碎片)      | 大块粗矿碎块                                 | 阶 V-a+ 化学压射室产物；硝化起爆器产物                     |

**规则**：新中间物优先复用产品状态表中已列出的状态；确无对应形态时才新增 `MaterialTypes`。

### 1.3 造渣焙砂与焙砂的差别

造渣焙砂 = 焙砂经压缩机加压注入石灰乳后的产物，脉石已结合成低熔点炉渣。两者入炉回收率不同(**75% / 88%**，见 §4.2)。

## 3. 矿物分级(原料准入表)

### 3.1 规则

**金属越晚，能进炉的料就越少。**除铁、铜、锌、金、锡、铅六种基础金属外，没有任何金属能从粗矿直接烧成成品。

**L3 另有一条流程分界**：**除铝外**，L3 金属的粗矿**必须先经硝化起爆器解离(1 粗矿 → 2 金属碎片)，才能进入粉碎轮** —— 前三个层级以粉碎轮开头，只有 L3 以硝化起爆器开头。

### 3.2 准入表

| 层级             | 金属                           | 允许直烧的原料形态                                                      | 必需的前提设备                            | 首次可用阶 |
| :--------------- | :----------------------------- | :---------------------------------------------------------------------- | :---------------------------------------- | :--------- |
| **L0 原矿级**(6) | 铁、铜、锌、金、锡、铅         | 矿石 / 粗矿 / 粉碎粗矿 / 粉 / 污浊粉                                    | 熔化炉(无前置)                            | 阶 I       |
| **L1 破碎级**(6) | 镍、银、钴、钛、阿迪特、埃特恩 | 粉碎粗矿 / 粉 / 污浊粉                                                  | 粉碎轮                                    | 阶 II      |
| **L2 选别级**(3) | 铂、铬、钒                     | 精矿 / 焙砂 / 粉                                                        | 振动台 + 鼓风机 + 热解炉                  | 阶 III     |
| **L3 提取级**(6) | 铝、铀、钨、锇、ostrum、desh   | **仅粉**；**除铝外**，粗矿必须先经硝化起爆器炸成 **2 金属碎片**才能粉碎 | **硝化起爆器(前置，阶 IV 解锁)** + 电解机 | 阶 IV ~ V  |

各层级对应的产物状态：L0 = 粗矿、L1 = 粉碎粗矿、L2 = 精矿 + 焙砂、L3 = 金属粉。
准入是**下限**(做不到就出不了锭)，产率阶梯是**回报**(做得越好，同样粗矿出锭越多)，两者正交。L0 金属同样可从阶 I 一路优化到阶 V(1.00 → 6.00 锭)。

### 3.3 L3 金属的前段路径

**硝化起爆器在阶 IV 解锁。**L3 中**除铝以外**的 5 种金属(铀、钨、锇、ostrum、desh)的粗矿**必须先经硝化起爆器解离才能进入粉碎轮**。

```
粗矿 ──硝化起爆器(前置解离)──▶ 2 金属碎片 ──粉碎轮──▶ 2 粉碎粗矿
```

未经硝化的这 5 种粗矿**没有粉碎配方**。

#### 铝：L3 中的例外

铝不加入硝化起爆前置 —— 大电解机的制造需要铝，若把铝推到硝化之后会形成「电解机需要铝 / 铝需要电解机」的循环。**铝改走小电解机(阶 III，材料为铁 + 银)出粉。**

```
铝土矿 ──粉碎轮──▶ 铝粉碎粗矿 ──振动台+鼓风机──▶ 铝精矿 ──热解炉(焙烧)──▶ 铝焙砂
       ──磨粉机──▶ 污浊粉末 ──化学反应釜(+烧碱溶液, 碱浸)──▶ 铝溶液 ──小电解机──▶ 铝粉
       ──熔化炉 937──▶ 铝锭
```

#### 其余 5 种：硝化前置后的两条路

```
【湿法路】
2 金属碎片 ──粉碎轮──▶ 粉碎粗矿 ──振动台+鼓风机──▶ 精矿 ──热解炉(焙烧)──▶ 焙砂
       ──磨粉机──▶ 污浊粉末(≤75μm) ──化学反应釜(+酸/碱)──▶ 溶液 ──电解机(电积)──▶ 金属粉(99.9%)
       ──▶ ★熔化炉 / MEK 电力熔炼炉 ──▶ 金属锭

【干法路】(工序更短)
2 金属碎片 ──粉碎轮──▶ 粉碎粗矿 ──振动台+鼓风机──▶ 精矿 ──磨粉机──▶ 污浊粉末
       ──富集机──▶ 金属粉 ──▶ ★熔化炉 / 红石熔炼炉 ──▶ 金属锭
```

### 4.2 造渣剂：二值开关(无配比)

| 熔炼条件     | 金属回收率 | 落地方式                          |
| :----------- | ---------: | :-------------------------------- |
| 焙砂(不造渣) |        75% | 直接入炉(无压缩机工序)            |
| **造渣焙砂** |    **88%** | 压缩机配方(+100 mB 石灰乳 + 蒸汽) |

```
1 焙砂 ────────────────────────────高炉(1542)──▶ 135 mB / 粗矿　(75%)
1 焙砂 ──压缩机(+100 mB 石灰乳 + 蒸汽)──▶ 1 造渣焙砂 + 余液 ──高炉(1542)──▶ 180 mB / 粗矿　(88%)
```

- 实现为**两个独立配方**，玩家在 EMI 中选取产率高的那个。
- 造渣剂必须以**流体**形式注入：熔化炉与高炉只接受单物品输入，石灰粉无法与焙砂一同投炉。**压缩机是加压反应器**(把气体或流体泵入粉末)，不是固体压块机。
- 造渣剂种类由矿种固定：含酸性脉石(石英质)的矿用**石灰乳**，含碱性脉石(方解石质)的矿用**石英浆**；两者都是流体，由粉料加水调制后经压缩机的流体槽泵入。
- 压缩机的第二路流体槽接**蒸汽**，加压同时升温。
- **对纯粉无效**：阶 IV 之后的金属粉已电解提纯，不含脉石。压缩机在阶 V 另有用途：把终渣与水泥浆加压固化成建材(§5.3 V-4)。

### 4.3 酸碱分工

| :--------------------------------------------- | :----------------------------- |

| **碱浸**(烧碱溶液 `cmi:caustic_soda_solution`) | 铝、钨、钒、铬(两性金属)       |

## 6. 尾矿处理体系

### 6.1 四个来源

| 编号 | 来源            | 组成                                | 品位             |
| :--- | :-------------- | :---------------------------------- | :--------------- |
| T1   | 阶 II 风选尾矿  | 细粒连生体(金属矿物 + 脉石，未解离) | 中(15~25%)       |
| T2   | 阶 III 离心尾渣 | 焙烧后铁硅酸盐、残余硫化物          | 低(5~10%)        |
| T3   | 阶 IV 浸出渣    | 酸不溶物 + 铅银渣 + 稀贵金属        | 极低品位但高价值 |
| T4   | 阶 V 终渣       | 硅酸盐 + 微量                       | 建材级           |

### 6.2 三级再处理

```
T1 ──离心分离机(重选)──▶ 再选精矿 ──回流熔化炉──▶ 金属
   └─ 离心尾渣 ──▶ T2
T2 + T1残渣 ──离心分离机──▶ 金属粉 + 副产元素 + 终渣 ──▶ 终渣入 T4
T3 ──化学反应釜(+酸, 二次浸出)──▶ 二次溶液 ──电解/置换──▶ 稀贵金属 ──▶ 终渣入 T4
T4 ──▶ 建材(液态混凝土 / 耐火砖 / 筑路石)
```

### 6.3 形态：物品

| 尾矿        | 产出设备                                  | 该设备的流体输出能力 | 尾矿形态         |
| :---------- | :---------------------------------------- | :------------------- | :--------------- |
| T1 风选尾矿 | 振动台(1 入 1 出)、鼓风机(1 入 1-4 出)    | **无**               | **必须是物品**   |
| T2 离心尾渣 | 离心分离机(1 入 4 物 **1 流出**)          | 有                   | 随 T1 统一为物品 |
| T3 浸出渣   | **化学反应釜**(3 物 3 流入 / 3 物 3 流出) | 有                   | 随 T1 统一为物品 |
| T4 终渣     | 离心分离机(1 入 4 出，1 路流出)           | 有                   | **必须是物品**   |

**结论**：尾矿统一为物品 `cmi:tailings`(+ 逐金属 `cmi:<m>_tailings`)，**不引入 `cmi:tailings_slurry`**。T1 来自振动台与鼓风机，两台设备都没有流体输出槽位，尾矿从诞生起就必须是物品。

### 6.4 逐阶尾矿回收的金属

**回收对象是该批矿石本身的伴生金属** —— 由玩家此前处理过哪些矿决定，不由阶段编号决定。

| 阶段   | 尾矿             | 处理方式                     | 回收的金属                                     | 去向                         |
| :----- | :--------------- | :--------------------------- | :--------------------------------------------- | :--------------------------- |
| 阶 II  | T1 风选尾矿      | 暂存                         | ——                                             | 尾矿池                       |
| 阶 III | T1 风选尾矿      | **离心分离机**(重选)         | **铁、铜、锌、铅、锡**                         | 再选精矿 → 熔化炉            |
| 阶 III | T2 离心尾渣      | 暂存                         | ——                                             | 尾矿池                       |
| 阶 IV  | T1 + T2 存量     | **化学反应釜**(二次**酸浸**) | **铜、锌、镍、钴、银**                         | 二次溶液 → 电解机            |
| 阶 IV  | T3 浸出渣        | **酸浸 + 锌粉置换**          | **金、银、铂**                                 | 贵金属粉 → 熔化炉 1092       |

**各级处理针对的金属**：重选(阶 III)= 粗粒连生体，比重差异大的金属(铁、铜、铅、锡、锌)；酸浸(阶 IV)= 酸溶性金属(铜、锌、镍、钴、银)；碱浸(阶 V)= 两性金属(钒、铬、钨)；离心重选(阶 V)= 万能解离后的细粒连生体。

## 7. 特殊处理线

### 7.1 金属联合处理系统

**对象**：自然生成较少或不生成的金属，不作为独立矿脉开采，而作为其他金属的副产物产出。

**范式**：把两种(或三种)金属的粗矿**混合投入**同一条联合线，各线**交错推进**(互相消耗对方上一步的副产物)，最终同时产出各自主金属与目标副产物。

|    # | 铁律         | 含义                                                 |
| ---: | :----------- | :--------------------------------------------------- |
|    1 | **两矿混投** | 联合线必须**同时投入**全部参与金属的粗矿，缺一不可   |
|    2 | **交错推进** | 各线**互相消耗对方的上一步副产物**，形成闭环依赖     |
|    3 | **唯一来源** | **目标副产物不在任何其他产线产出**                   |
|    4 | **同期可玩** | 各线的**解锁阶段必须重叠**，否则先解锁的一方长期空等 |

| 共同参数   | 值                                                                                                    |
| :--------- | :---------------------------------------------------------------------------------------------------- |
| 可用阶     | 阶 IV 起(需要化学反应釜 + 电解机 + 硫酸)                                                              |
| 产率影响   | **不占主线的 4.00 / 6.00 定额**，副产物为额外产出                                                     |
| 尾矿       | 并入 §6 的处理体系                                                                                    |
| 中间物状态 | 复用产品状态：含铂重砂 = `cmi:platinum_clump`(金属碎块)、阳极泥 = `cmi:platinum_dirty_dust`(污浊粉末) |
| 前置       | 三条线各自作为任务书的独立支线                                                                        |

### 7.2 A：金 + 银 → 铂

**原料**：金粗矿、银粗矿　　**目标副产物**：铂　　**阶段**：阶 IV(金线 L0、银线 L1 各自跑通)

```
【第 1 步 · 并行】
  金粗矿 ──粉碎轮──▶ 金粉碎粗矿
  银粗矿 ──粉碎轮──▶ 银粉碎粗矿

【第 2 步 · 交错一｜银线取用金线】
  银粉碎粗矿 + 金粉碎粗矿(捕集剂)──振动台──▶ 银精矿 + 含铂重砂
  (含铂重砂 = cmi:platinum_clump「金属碎块」)

【第 3 步 · 交错二｜金线取用银线】
  金粉碎粗矿 + 含铂重砂 ──热解炉(焙烧)──▶ 金焙砂 + 铂渣

【第 4 步 · 交错三｜银线取用金线】
  银精矿 + 少量金焙砂 ──化学反应釜(+硫酸)──▶ 银溶液 + 渣

【第 5 步 · 并行】
  金焙砂 ──化学反应釜(+硫酸)──▶ 金溶液 ──电解──▶ 金粉(→ 金锭)
  银溶液 ──电解──▶ 银粉(→ 银锭)+ 阳极泥
  (阳极泥 = cmi:platinum_dirty_dust「污浊粉末」)

【第 6 步 · 收口】
  阳极泥 ──精炼(结晶机 / 化学压釜)──▶ 铂粉 ──▶ 铂锭
```

**产物**：金锭 + 银锭 + 铂 + 尾矿。第 2 步的捕集剂对应贵金属冶炼的铅试金法与灰吹法；第 6 步对应电解精炼阳极泥。

### 7.3 B′：粗铁 + 蓝宝石(铁-铝)→ 钛

**原料**：粗铁、蓝宝石(Al₂O₃)　　**目标副产物**：钛(**唯一来源**，原蓝宝石单线处理停用)　　**阶段**：铁线阶 III(高炉)、蓝宝石线阶 IV，两条线解锁期重叠

```
【第 1 步 · 并行】
  粗铁 ──粉碎轮──▶ 铁粉碎粗矿
  蓝宝石 ──粉碎轮──▶ 蓝宝石粉(Al₂O₃)

【第 2 步 · 交错一｜铁线取用蓝宝石线】
  铁粉碎粗矿 + 蓝宝石粉 ──振动台──▶ 铁精矿 + 含钛重砂

【第 3 步 · 交错二｜蓝宝石线取用铁线】
  含钛重砂 + 铁精矿 ──热解炉(焙烧)──▶ 富钛焙砂 + 铁焙砂

【第 4 步 · 并行】
  铁焙砂 ──高炉(1542)──▶ 铁锭 + 含钛炉渣
  蓝宝石粉 ──化学反应釜(碱浸) + 电解机──▶ 铝粉

【第 5 步 · 交错三｜铁线取用蓝宝石线的铝】
  富钛焙砂 + 含钛炉渣 + 铝粉 ──铝热还原(熔化炉 / 红石熔炼炉 ≥ 2000)──▶ 粗钛 + 氧化铝渣

【第 6 步 · 收口】
  粗钛 ──红石熔炼炉(2000) / 电弧炉(2115)──▶ 钛锭
  氧化铝渣 ──回流蓝宝石线──▶ 循环
```

**产物**：铁锭 + 钛 + 氧化铝渣(回流)+ 尾矿。对应钛铁矿 FeTiO₃ 与铝热还原(Al 还原 TiO₂)；蓝宝石即 Al₂O₃，同时充当铝源与脉石载体。铁渣入尾矿池。

### 7.4 C′：铬 + 铜 + 锇(三线交错)→ 锇粉

**原料**：铬粗矿、铜粗矿、粗锇　　**目标副产物**：锇(**唯一来源**)　　**阶段**：定位为**阶 V 终局内容**(铜线阶 I、铬线阶 III~IV、锇线阶 V)

```
【第 1 步 · 并行】
  铬粗矿 ──粉碎轮──▶ 铬粉碎粗矿
  铜粗矿 ──粉碎轮──▶ 铜粉碎粗矿
  粗锇 ──硝化起爆──▶ 2 金属碎片 ──粉碎轮──▶ 锇粉碎粗矿(第三股料)

【第 2 步 · 交错一｜铜线取用铬线】
  铜粉碎粗矿 + 铬粉碎粗矿 ──振动台──▶ 铜精矿 + 含锇重砂

【第 3 步 · 交错二｜铬线取用铜线】
  铬粉碎粗矿 + 含锇重砂 ──热解炉(焙烧)──▶ 铬焙砂 + 锇富集渣

【第 4 步 · 交错三｜锇粉在此产生】
  锇粉碎粗矿 + 锇富集渣 + 铜精矿 ──化学反应釜(+烧碱溶液)──▶ 铬溶液 + 铜溶液 + 锇粉

【第 5 步 · 并行】
  铬溶液 ──电解机──▶ 铬粉 ──▶ 铬锭(→ 不锈钢原料)
  铜溶液 ──电解机──▶ 铜粉 ──▶ 铜锭

【第 6 步 · 收口】
  锇粉 + 注入烈焰血 1000 mB ──红石熔炼炉(等效上限 3094)──▶ 锇锭(1 入 → 1 出)
```

**产物**：铬锭 + 铜锭 + 锇锭 + 尾矿。对应锇铱矿天然赋存于铬铁矿、铬铁矿走碱熔氧化路线(碱浸)。铬渣二次碱浸回收铬、钒。

**前置**：硝化起爆器、化学反应釜、电解机、红石熔炼炉 + 烈焰血供应。
