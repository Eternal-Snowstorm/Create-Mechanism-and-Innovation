## 可以使用的设备:
- 所有涉及到多输入/多输出的设备, 其标*的输入/输出可酌情减少
| 设备名 | 输入输出概况 | 所需材料 | 备注 |
| 熔炉 | 1物入 1物出 | 开局攒的石头 | 最早的矿物处理设备 |
| 熔化炉 | 1物入 1流出 | 沙子, 粘土, 沙砾 | 可以通过更换燃料覆盖所有金属的熔点, 但高级燃料有用于卡阶段 |
| 浇筑台 | 1物1流入, 1物出 | 沙子, 粘土, 沙砾 | 可用锌浇筑生产安山合金 |
| 锤子 | 1物入, 1物出 | 燧石, 木棍 | 设定用于敲碎矿物 |
| 高炉 | 1物入, 1物出 | 安山合金 | 封闭式的熔炉, 温度高于熔炉 |
| 密封处理 | 1物1流入*, 1物1流出* | 安山合金 | 可用于浸泡等设定的配方 |
| 振动台 | 1物入, 1物出 | 安山合金 | 无 |
| 鼓风机 | 1物入, 1-4物出* | 安山合金 | 可用于洗涤等设定的配方
| 石磨 | 1物入, 1物出 | 安山合金, 安山岩 | 
| 注液器 | 1物1流入, 1物出 | 铜, 锌, 安山岩 |

## 已有的金属材料状态
- **本表格中的所有金属材料状态预设成还没使用的状态, 在重构过程中可以重新放置于任意步骤**
| 状态 | 备注 |
| 矿石(ore) | 方块状态的矿物, 挖掘产出1-4个粗矿 |
| 粗矿(raw_material) | 一般获取到的基础矿产状态 |
| 粉碎粗矿(crushed_raw_material) | 粗矿经过粉碎轮粉碎的产物 |
| 矿物碎块(raw_nugget) | 粉碎粗矿4:1矿物碎块, 彼此合成 |
| 污浊粉末(dirty_dust) | 进一步粉碎的粗矿, 含有杂质的金属粉末, 甚至大多是金属化合物 |
| 金属碎块(clump) | 一种大块的粗矿碎块, 原本是提纯仓粉碎产物 |
| 金属碎片(shard) | 一种大块的粗矿碎块, 原本是压射室粉碎产物 |
| 粉末(dust) | 金属单质的粉末, 可以烧结成金属锭 |
| 金属锭(ingot) | 一般的金属储存状态 |
|熔融金属(molten_metal) | 顾名思义, 是熔融态的金属单质 |
| 溶液(solution) | 作为金属盐混合物溶液的状态 |
| 晶体(crystal) | 溶解结晶产线的产物, 用于倍产矿物 |
| 金属混合物(mixture) | 粉末, 但是和污浊粉末分别的点是其中的金属化合物被还原了 |
