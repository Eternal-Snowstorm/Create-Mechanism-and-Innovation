# TCon 武器 build 流派策划案

> 配套文档：[TCon武器平衡分析案.md](TCon武器平衡分析案.md)（本文只写「怎么配、配出来什么」, 推导与代码依据见分析案）。
> 本文为设计方案, 未对整合包做任何修改。

---

## 〇、设计前提

**七条铁律**

- **强度锚点**：毕业弓（紫金弓臂 ×2 + 3 箭齐射）贴脸 **85.7 DPS**；毕业近战四个流派各落 **85~88 DPS**。
- **技能绑材料, 不绑槽位**。槽位可无限购买（`tconstruct:writable` / `draconic` 无等级上限）, 若技能占槽则玩家会四个全装、倍率互乘；材料结构上不可通吃（一把剑只有一个主刃）, 是唯一能保证「同一时刻只有一条流派生效」的约束。
  - 落地手段见 3.7：技能材只给 `head`、技能 hook 检查材料唯一性、武器 / 工具用物品标签分流。
- **三层强度结构**
  - 第 1 层 **材料层**：材料固有 trait, 免费不占槽 → 目标 85~88（锚点）
  - 第 2 层 **投入层**：针对性强化件, 成本 = 材料 + 时间 → 目标 110~130（设计上限）
  - 第 3 层 **消耗层**：每发成本 → **仅弓有**（光辉石箭）, 近战没有
- **互斥必须靠机制语义, 不能靠槽位占用**。弓的两条流派在代码层读等级互斥。
- **材料池可扩展（D10 已裁定走新材料路线）**。技能载体不必局限于现有材料：金属表里还有 11 个「物品已存在、熔点已登记、材料未注册」的对象, 可现注册为流派专属载体；载体必须只给 `head`（见 3.3 / 3.5）。
- **材料层即冲突层**。流派冲突尽量前移到材料选择：武器材带战斗技能、工具材带采集强化、通用材两不沾；技能只在武器标签上生效, 工具标签上自动静默（见 3.7）。
- **平衡范围与分档锚点**。需要平衡的是十件武器：匕首 `dagger`、剑 `sword`、劈刀 `cleaver`、短柄斧 `hand_axe`、板斧 `broad_axe`、镰 `scythe`、大锤 `sledge_hammer`、标枪 `javelin`、长弓 `longbow`、弩 `crossbow`（`kama` / `vein_hammer` / `battlesign` 与镐类不在范围内）。三档验收：
  - **单体档**（剑 / 匕首 / 短柄斧 / 标枪 / 长弓 / 弩）：85.7（±15% ⇒ 73~99）
  - **AOE 档**（劈刀 / 镰）：**3 目标合计 85.7**
  - **团队档**（板斧 / 大锤, 破防增益向）：55~70, 用「全队受到的伤害 +20%」兑换单体缺口
  - 低基础补偿一律**按攻速缩放技能倍率**, 不许通胀攻击力（攻速越低追加越高）

**两条成本形态差异（刻意保留）**

- 弓的上限 124.3 是「每发付费」；近战的上限 110~130 是「装完永久有效」。
- 因此近战不设消耗层, 但上限卡 130 以内, 不许出现「永久有效的 150」。

## 一、远程侧：四条流派（长弓 2 + 弩 1 + 标枪 1）

### 流派 A｜收束齐射（单体远射型, 首推）

**定位**：把「3 箭齐射」的空间分散问题用 converge 收束, 换取远距离满伤。

- **载体**：长弓 / 弩 + `nebula_tinker:converge`
- **材料路线**（四级递增）
  - L1 工业铁弓臂 ×2：单箭 8, 射速 1.333, 贴脸 32.0
  - L2 不锈钢弓臂 ×2：单箭 10, 射速 1.333, 贴脸 40.0
  - L3 戴斯弓臂 ×2：单箭 14, 射速 1.429, 贴脸 60.0
  - L4 紫金弓臂 ×2：单箭 20, 射速 1.429, 贴脸 **85.7**
- **核心件**：converge **4 级**（`upgrades 1`, 材料 `thermal:rf_coil` + `functionalstorage:redstone_upgrade`）
  - 满伤圈（三箭全中）随等级：0 级 1.70 / 1 级 2.13 / 2 级 2.85 / 3 级 4.29 / **4 级 8.60 格**
  - 5 级及以上是完全收敛（三箭轨迹重合、满伤圈不受几何限制）⇒ **配方上限锁 4 级**, 否则等于取消距离分层
- **配套投入**
  - `accuracy` 拉满（`inaccuracy = 3.0 × (1/accuracy − 1)`, 1.0 时零随机散布）
  - `tconstruct:lightweight`（每级 `attack_speed` / `draw_speed` / `velocity` 各 +3~8%）—— 只提射速与箭速, 不改单箭
  - 消耗层：光辉石箭头（`refined_radiance` 的 `ammo` 组已是 `keen 2`, 每级 +0.5 projectile_damage）⇒ 单箭 20 → **29**
- **互斥**：`cmi:point_blank` 在代码层读 converge 等级 > 0 即失效
- **生态位**：3 格以外的所有场合；对 Boss 大碰撞箱可延伸到 17~29 格

### 流派 B｜贴身散射（6 格内群伤型, 与齐射互斥）

**定位**：不追求射程, 把 3 箭的落点变成 3 次小范围爆炸, 专打贴身小怪群。

- **载体**：长弓 / 弩 + `cmi:point_blank` 1~3 + `cmi:scatter_lens`
- **核心件**
  - `cmi:point_blank`（`upgrades 1`, `level 1~3`）：命中点距射手 **≤ 6 格** 时, 对命中点 **1.5 格内最多 2 个**其他生物各受 **40% / 55% / 70%** × 该次箭直接伤害；不暴击、不触发技能层数、同 tick 同目标只吃一次箭爆
  - `cmi:scatter_lens`（`upgrades 1`, `level 1`）：箭爆波及目标数 2 → **3**（需 `point_blank` 前置）
- **配套投入**
  - `tconstruct:lightweight 2`：射速 1.429 → **1.538**（横向提速, 允许）
  - 光辉石箭头：单箭 20 → 29
- **互斥**：与 converge 互斥（同占 `upgrades 1` 只是心理提示, 真正的约束是 `point_blank` 各 hook 入口读 converge 等级后直接返回原值）
- **生态位**：6 格内的刷怪塔、小怪群、要塞走廊；与近战溅射强化抢同一块地盘

### 流派 C｜装填齐射（弩专用）

**定位**：弩只有 **1 根弓臂**（`crossbow.json` 的 parts 只有 `bow_limb` ×1）, `VELOCITY` 与 `DRAW_SPEED` 各只吃 1 份 `limb`, 裸 DPS 天然只有长弓的一半；用「装填」这个长弓没有的动作换一次齐射爆发。

- **载体**：`tconstruct:crossbow` + 新材料技能 `cmi:volley`（挂 `tconstruct:ranged` 组的 `limb`, 见 3.3）
- **装填机制（代码确证）**
  - `ModifiableCrossbowItem.m_5551_`：松手时若 `72000 − chargeRemaining ≥ KEY_DRAWTIME` 且没有已装填的弹药, 才 `consumeAmmo` 并把整组箭写进 NBT `tconstruct:crossbow_ammo`
  - `fireCrossbow`：把 NBT 里那**一整组箭**一次性射出（箭数 = `ammo.getCount()`）, 每支间隔 10°（绕竖直轴 rotate ⇒ **水平扇形**）, 而且**每支无条件暴击**（`arrow.m_36762_(true)`）
  - ⇒ 弩的箭数不受 `multishot` 独占：背包里装几支就射几支, `multishot` 在此之上再叠加
- **数值**（紫金弓臂 1 根, `velocity 1.1` / `drawSpeed 0.25`）
  - `VELOCITY = 1 + 1.1 = 2.1` ⇒ 单箭 `ceil(6 × 2.1) = 13`
  - `DRAW_SPEED = 1 + 0.25 = 1.25` ⇒ `drawtime = 16t`；装填 + 发射周期 ≈ **19t** ⇒ **1.05 发/秒**
  - 箭数 `N = 1 + 2 × multishot`, 弓臂材料挂 `multishot 1` ⇒ **3 箭**
  - 裸 DPS = `13 × 3 × 1.05 = 41.0`（不含暴击；弩无条件暴击, 期望 ×1.25 ⇒ 51.2）
- **技能 `cmi:volley`**：装填完成（`tconstruct:crossbow_ammo` 被写入）后的**下一次齐射**, 每支箭伤害 **×2.1**, 发射后清除
  - `41.0 × 2.1 = 86.1` ⇒ 正好落在单体锚点 85.7
  - 长弓天然吃不到：长弓没有 `tconstruct:crossbow_ammo` 这个 NBT, 判定直接失败（不需要额外的武器类型过滤）
- **强化件**
  - `cmi:quick_load`（`upgrades 1`, `level 1~2`）：`DRAW_SPEED +0.1/级` ⇒ 装填 16t → 13t, 射速 1.05 → 1.25
  - `cmi:volley_core`（`abilities 1`）：齐射倍率 ×2.1 → ×2.6 ⇒ **106.7**（投入档）
  - 原生 `tconstruct:multishot`（每级 +2 箭）：3 → 5 箭 ⇒ 单体 143, 但散布 ±20°, 只有贴脸才全中
- **生态位**：预装填后的贴脸爆发。`converge` 对它**无效** —— Nebula 的 `ModifiableBowItemMixin` 只 Redirect `ModifiableBowItem.releaseUsing`, 弩走的是 `fireCrossbow` 的 rotate 路径。所以弩的定位是「站位换伤害」, 与长弓的两条路线都不同

### 流派 D｜投掷穿刺（标枪专用）

**定位**：标枪的 parts 同时含 `small_blade` / `tool_handle` 与 `bow_limb` / `bow_grip` ⇒ 它**既吃近战材料（刃）也吃弓材料（弓臂、弓把）**；投掷伤害 = `ATTACK_DAMAGE × VELOCITY`（`ThrownTool.m_5790_` 里 `.baseDamage(tool.ATTACK_DAMAGE × multiplier)`, `multiplier` 就是 `VELOCITY`）。

- **载体**：`tconstruct:javelin` + 新材料技能 `cmi:impale`（挂 `melee_harvest` 组的 `head`, 见 3.3）
- **投掷链路（代码确证）**
  - `ThrowingModule.onToolUse`：`speed = DRAW_SPEED × ATTACK_SPEED`（因为 javelin 在 `#tconstruct:modifiable/melee/weapon` 里）, `KEY_DRAWTIME = ceil(20 / speed)`
  - `onStoppedUsing`：`chargeTime > 10` 才投出；初速 `charge × VELOCITY × 2.0`；非创造消耗 1 支
  - 命中走 `ToolAttackUtil.performAttack` ⇒ **吃近战 hook、吃暴击、吃 AOE 模块**；`cooldown = charge` ⇒ 必须拉满, 否则伤害按 `0.2 + 0.8 × charge²` 骤降
- **数值**（耐热金属刃 + 紫金弓臂 + 紫金弓把）
  - `ATTACK_DAMAGE = (3.0 + 6.5 + 3.0 + 3.5) × 1.30 + 1.0 = 21.8`（含 `cmi:heavy_edge` 2 级与弓把的 `melee_damage 3.5`）
  - `VELOCITY = 1 + 1.1 = 2.1` ⇒ 单发 **45.8**
  - `DRAW_SPEED = 1.25`、`ATTACK_SPEED ≈ 0.935` ⇒ `speed = 1.17` ⇒ `drawtime = 18t` ⇒ 理论 1.11 发/秒
  - 计入回收（不装 `returning` 时得跑过去捡）⇒ 实战 **0.9~1.0 发/秒**, 裸 DPS **41~46**
- **技能 `cmi:impale`**：投掷命中追加 **85%** 穿甲伤害, 并**贯穿**：沿飞行方向 2 格内最多 2 个后续目标各吃 **60%**（追加段不暴击、不触发其他技能层数）
  - 单体 `45.8 × 1.85 = 84.7` ⇒ 单体锚点
  - 贯穿 3 目标 ≈ `45.8 + 45.8×0.85 + 2×45.8×0.6 = 139.7`
- **强化件**
  - `tconstruct:returning`（原生）：投出后自动返回 ⇒ 射速稳定 1.11, DPS 约 94
  - `cmi:pierce_lens`（`upgrades 1`）：贯穿目标 2 → 3
- **与近战的隔离**：标枪裸近战 20.4（单击 21.8 / 攻速 0.935）, 投掷间隔 18t 而攻击冷却 `C = ceil(20/0.935) = 22t` ⇒ 投掷的节奏永远踩不进精准突击的判定窗（`[C, C+J]`）, **投掷流天然不吃近战技能**, 这是刻意的隔离

### 弓侧的「不构成流派」路线（留档）

- **疾速薄射**：`featherweight 2` + 不锈钢弓臂 ×2 ⇒ 射速换伤害, 46.2 DPS, 天然低于锚点 ⇒ 自我降级换手感, **不需平衡干预**
- **虚空蚀射**：暗影钢 `ranged shadow 2` 每箭 +3 真实伤害并清 i-frame, 3 箭 +9 ≈ +10%, 落在锚点 ±15% 容差内 ⇒ 视为材料固有溢价, **不做独立流派**（做流派需另配强化件, 工作量过大）
- **弹种特化**：本质是流派 A 的消耗层通道, 不单列

## 二、近战侧：五个材料专有技能

### 共同地基：`cmi:heavy_edge`

- **是什么**：`melee_harvest` 材料 trait, `stat_boost attack_damage` 每级 **+1.5**（add）, 上限 2 级
- **为什么需要**：tier4 剑裸值 19.4, 走满倍率只到 74, 差锚点 14%
- **怎么挂**：tier4（紫金 / 戴斯 / 耐热金属 / 五个新近战载体）挂 **2 级**（+3.0）；tier3（黄铜 / 铸铁 / 暗影钢 / 阿迪特 / 不锈钢 / 光辉石）挂 **1 级**（+1.5）；tier2 不挂
- **纪律**：不许靠加它解决平衡（到 86 需约 29 级, 单击 60 会让僵尸/末影人一刀必死）；它的职责只是让倍率落在「8~10 层 / 4~5 段」这种看得见的区间

**tier4 各武器裸 DPS（含 heavy_edge 2 级）**

- 剑 25.0（单击 17.5 / 攻速 1.45）
- 匕首 17.4（9.4 / 1.85）
- 劈刀 16.8（19.8 / 0.85）
- 短柄斧 14.9（16.6 / 0.90）
- 矿锤 14.4（16.9 / 0.85）
- 战斧 14.3（23.8 / 0.60）
- 大锤 14.3（19.1 / 0.75）
- 战牌 11.8（9.8 / 1.20）
- 镰刀 kama 11.2（7.0 / 1.60）
- 镰 scythe 8.1（11.6 / 0.70）
- 标枪 20.4（21.8 / 0.935, 含弓把 `melee_damage 3.5` 与弓臂 `velocity`）
- 弩 41.0（单箭 13 / 射速 1.05, 单弓臂）

注：矿锤 / 战牌 / 镰刀 kama 不在用户给定的十件武器名单内, 仅列出以说明跨度；它们的技能照常生效但不作验收项。

### 技能一｜精准突击（Precision Strike）

- **载体材料**：本命 **铬 `chromium`**（tier4, 待注册, **只给 `head` 组**）；现成可用 **戴斯**
- **适配武器**：**剑、镰 scythe**（冷却适中, 既连击密度够、判定窗也比极快/极慢武器更从容）；**类型过滤 `ATTACK_SPEED ≥ 0.6` 且属于 `#tconstruct:modifiable/melee/weapon`**
  - 镰的 `circle_melee 2.0` 会对每个目标各走一次 `performAttack` ⇒ 技能**逐目标结算**, 3 目标即 3 次判定 ⇒ 单体 27.5 / 3 目标 **82.5**
  - 镰刀 kama（1.60）与矿锤（0.85）技术上也在窗内, 但不在十件名单内, 不作验收
- **设计来源**：怪物猎人系列片手剑的「精准突击」—— 判定达成即把该次攻击的伤害乘一个固定倍率, **没有层数、没有爬坡、不留缓存**
- **判定量 = 时机**
  - 记上次命中 `t_prev`、本次 `t_now`, `gap = t_now − t_prev`
  - 武器冷却 `C = ceil(20 / attackSpeed)`（取玩家当前 `ATTACK_SPEED` 属性实时算, 不缓存）
  - 判定窗 `W = [C, C + J]`, 容差 `J = max(3, ceil(C × 0.25))`
  - `gap ∈ W` ⇒ **判定达成**；否则判定失败
- **效果（固定倍率, 不叠层）**
  - 判定达成：该次伤害 **× M**, `M = 1.4 + 0.5 × 材料等级`
  - 材料挂 **4 级** ⇒ `M = 3.40` ⇒ 剑 25.0 → **85.0 DPS**
  - 等级表：L1 ×1.90 / L2 ×2.40 / L3 ×2.90 / L4 **×3.40** / L5 ×3.90（材料最多挂到 4 级）
  - 判定失败：该次伤害 **×1.0**（不惩罚, 只是没吃到倍率）
- **为什么不做成叠层**（m01859 裁定）
  - 叠层的实际体验是「前几击弱、爬满才强」, 中间被打断就归零 ⇒ 玩家在两次失误之间反复等爬坡
  - 固定倍率是「每一次都在赌判定」, 判定成功立刻见效, 手感与 MH 片手剑一致
  - 数值上限完全一样（都是 ×3.4、85.0 DPS）⇒ 第二章其余三个技能的倍率与目标不用重算
- **达成率与期望**
  - 「冷却一好就点」⇒ `gap = C` ⇒ 必定落在窗口内 ⇒ **100% 达成, 稳定 85.0**
  - 点太早（`gap < C`）或拖沓（`gap > C + J`）⇒ 该次 ×1.0；早点的伤害还要吃 `ToolAttackUtil` 的冷却衰减（`0.2 + cooldown² × 0.8`, 最低两成）
  - 期望值：达成率 100% / 80% / 60% ⇒ 剑 **85.0 / 73.0 / 61.0**（这是本流派唯一的「操作税」）
- **强化件**
  - `cmi:tempo_window`（`upgrades 1`, `level 1~2`）：容差 `J` 每级 +1 tick ⇒ 提高达成率, 不提高上限
  - `cmi:precision_edge`（`abilities 1`, `level 1`）：判定达成时倍率再 ×1.15 ⇒ 剑 **97.8**
  - `cmi:step_in`（`upgrades 1`, `level 1`）：判定达成时返还 2 tick 攻击冷却 ⇒ 等效攻速提高, 剑约 **92**
  - 原生 `tconstruct:swiftstrike`（提高攻速 ⇒ 缩短 C, 窗口更早出现、判定更密）
- **禁区**
  - 与 `nebula_tinker:killing_rhythm` 叠乘会让剑到 160+
  - 追加段（回声连斩 / 破防重击）不得触发 `acupoint` 血量斩
- **手感特征**：判定是「每一次」的, 不积累也不清算 ⇒ 判定窗宽 `J = max(3, ceil(C × 0.25))` 随冷却等比伸缩, 所以**冷却适中的剑（C=14、J=4）与镰（C=29、J=8）都能稳定达成**；匕首（C=11、J=3）窗口最密但容错时间最短, 战斧（C=34、J=9）窗口最宽但机会最少。设计取向是「中等冷却最舒服」, 不是「越快越强」

### 技能二｜回声连斩（Echo Slash）

- **载体材料**：本命 **钨钢 `tungsten_steel`**（tier4, 待注册）；现成可用 **暗影钢**（走 `melee_harvest` 组时需替换其 `shadow 1`, `ranged` 的 `shadow 2` 保留 —— 换钨钢后这个取舍消失）
- **适配武器**：**镰 scythe、匕首、剑**（MH 太刀「樱花斩」式的多段连击）；近战武器且非纯采集工具, 不设攻速门槛
  - 标枪的投掷也会触发 `onAfterMeleeHit`（`context.isProjectile()` 为真）⇒ 必须显式排除, 否则投掷会白拿五段追加
  - 镰刀 kama（71.5）技术可走, 但不在十件名单内, 不作验收
- **效果**：命中后按 tick 追加 5 段
  - 延迟 4 / 8 / 12 / 16 / 20 tick
  - 每段比例 80% / 80% / 80% / 80% / 100%（合计 **+420% ⇒ ×5.20**）
  - 每段取 `max(比例 × 本次伤害, 8)`（floor 8：低于 8 会被护甲吃掉看不出来；再高就会让匕首、镰刀这种「低单击高攻速」武器白拿固定加值并被攻速放大过头）
  - 走 `ToolAttackUtil.hurtNoInvulnerableTime`：不产生击退、不暴击、不触发其他技能层数、不触发血量斩
- **强化件**
  - `cmi:echo_lance`（`abilities 1`, `level 1~2`）：每级 +1 段 ⇒ 7 段约 ×6.8
  - `cmi:echo_delay`（`upgrades 1`）：段间隔 −1 tick
  - 原生 `nebula_tinker:death_echo`（暴击系）
- **禁区**：`acupoint`（20 tick 内从满血到 1 血且不可中断）
- **手感特征**：单击低、段数多, 命中后 20 tick 内连续跳 5 个数字, 这是樱花斩的手感；floor 8 专门用来托起匕首、镰刀、镰这类低单击武器, 让它们不因基础伤害低而被开除出流派

### 技能三｜溅射强化（Glow Splash）

- **载体材料**：本命 **红钕 `scarlet_neodymium`**（tier4, 待注册）；现成可用 **紫金**
- **适配武器**：**重武器中自带生物 AOE 的两把 —— 劈刀 `cleaver`（`sweep_melee 2.0`）与镰 `scythe`（`circle_melee 2.0`）**
  - 理由：「溅射」这个名字指向重武器, 而重武器里只有劈刀与镰自带**生物** AOE；大锤、板斧只有**方块** AOE（`box_aoe`, 对生物无效）, 因此不进本流派
  - 剑与镰刀虽也自带生物 AOE, 但属轻武器, 按 m01984 归给精准突击 / 回声连斩, 不占溅射的位置
- **效果**：命中后 6 tick 结算「光爆」
  - 半径 **2.5 格**内最多 **8 个**其他生物各受 **240%**（走 `attackEntitySecondary`, 无击退）
  - 主目标额外受 **240% 回灌**
  - 每波及 1 个目标主目标再 +5%（上限 +20%）
  - 光爆不触发其他技能层数；自带 AOE 照常结算, 光爆是额外一层
- **强化件**
  - `tconstruct:expanded`（`abilities 1`, 原生）：每级 +1 范围 —— 两条 WeaponAttack 都读 volatile EXPANDED, **对无 AOE 模块的武器无副作用**, 是「只给已有 AOE 武器」最省事的实现
  - `cmi:splash_focus`（`upgrades 1`, `level 1~2`）：回灌 +40%/级
  - `cmi:quake_core`（`abilities 1`）：波及 ≥3 目标时触发 100% 震荡
  - 原生 `tconstruct:sweeping_edge`（仅剑/劈刀；未装时横扫只有 1.0 点）
- **注意**：`sweep_melee` 直接 `aoeTarget.hurt()` 不吃近战 hook, `circle_melee` 走 `performAttack` 全吃 hook ⇒ 两套模块的数值表现不同, 验收要分开测
- **生态位**：3~6 目标的小怪群, 这是近战唯一能稳定超过弓的场景

### 技能四｜破防重击（Guard Break）

- **载体材料**：本命 **铂 `platinum`**（tier4, 待注册）；现成可用 **耐热金属**
- **适配武器**：**板斧、大锤、劈刀**（「重击」指向重武器）；**类型过滤 `ATTACK_SPEED ≤ 1.0`**
  - 板斧 0.60 / 大锤 0.75 / 劈刀 0.85 都在窗内；短柄斧 0.9 可生效但本命是处刑（两者互斥, 见下方分工）
  - 注意：大锤与板斧只有方块 AOE, 对生物无群体收益 ⇒ 它们的破防档只算单体
  - **按攻速缩放**：追加倍率 = `500% × (0.9 / attackSpeed)`, 攻速越低追加越高 —— 板斧 750%、大锤 600%、劈刀 529%
- **效果**
  - 计数 key =（玩家, 目标）, **每第 2 次**命中追加 `500% × (0.9 / attackSpeed)`（走 `hurtNoInvulnerableTime` + `damageSources().generic()` 穿甲）
  - 同时给目标「破防」：受伤 **×1.20**, 100 tick, 只刷新不叠加
  - 追加段不暴击、不触发其他技能层数
  - 平均乘数 `1 + 追加倍率 / 2` ⇒ 板斧 **×4.75**（14.3 → **67.9**）、大锤 **×4.00**（14.3 → **57.2**）、劈刀 **×3.65**（16.8 → **61.3**）
  - 缩放的用意：攻速越低, 单次追加的绝对值越接近「同 DPS 下的单击伤害 × 2.5」, 让三把重武器落在同一个 55~70 的团队档里
- **强化件**
  - `cmi:sunder`（`upgrades 1`, `level 1~2`）：破防受伤 +10%/级（最高 40%）
  - `cmi:hammerfall`（`abilities 1`）：每次命中都触发, 但追加降到 200%（锤专精）
  - 原生 `tconstruct:smite`
- **为什么第 2 次不是第 3 次**：第 3 次需单次 1000%（单击追加 170, 像 Bug）；提高频率、降低单次更容易读也更好平衡
- **生态位**：Boss 与高血量目标；团队收益最高（破防是全队共享的受伤加成）

### 技能五｜处刑（Execution）

- **载体材料**：本命 **钒 `vanadium`**（tier4, 待注册）；现成可用 **耐热金属**
- **适配武器**：**短柄斧 `hand_axe`**（`ATTACK_SPEED = 0.9`）；类型过滤 **`0.8 ≤ ATTACK_SPEED ≤ 1.0`**
- **效果**
  - 计数 key =（玩家, 目标）, **每第 2 次**命中触发处刑：追加 `900% × (0.9 / attackSpeed)` 的伤害（短柄斧 as 0.9 ⇒ **900%**）, 走 `hurtNoInvulnerableTime` + `damageSources().generic()` 穿甲
  - 追加段不暴击、不触发其他技能层数
  - 平均乘数 `×5.50` ⇒ 短柄斧 14.9 → **82.0**
  - 与破防重击的分工：破防是**团队**向（破防 +20%, 全队共享）, 处刑是**单体**向（纯倍率、无状态、无团队增益）
- **强化件**
  - `cmi:execution_edge`（`upgrades 1`, `level 1~2`）：处刑追加 +10%/级 ⇒ 900% → 1100%
  - `cmi:merciless`（`abilities 1`）：目标生命低于 50% 时处刑追加 ×1.5
- **为什么给短柄斧**：它是名单里唯一的「单击 16.6 / 攻速 0.9」中间态（板斧 0.6 太慢、剑 1.45 太快）, `×(0.9 / attackSpeed)` 的缩放正好把它抬到单体档
- **注意**：短柄斧自带的是 `circle_aoe`（**方块** AOE, 对生物无效）⇒ 处刑是纯单体技能, 不提供任何群体收益

### 技能的过滤：三层闸门（必须写进代码）

**第 1 层 · 武器 / 工具分流（`tconstruct:modifiable/melee/weapon`）**

- 五个技能的第一行一律 `if (!isWeapon(tool) || context.isProjectile()) return 原值;`, 判定用物品标签 `#tconstruct:modifiable/melee/weapon`（`TinkerTags.Items.MELEE_WEAPON`, 其 values 为 `#modifiable/melee/primary` + `/sword` + `/parry`）
- 采集工具（`#tconstruct:modifiable/harvest`）永远不会触发战斗技能, 即使刃部用的是武器材
- 反过来, 工具材的采集技能一律用 `#tconstruct:modifiable/harvest` 判定, 不进入武器侧

**第 2 层 · 武器类型细分**

- 精准突击：`ATTACK_SPEED ≥ 0.6`（剑 / 镰）
- 回声连斩：非纯采集的近战武器即可, 不设攻速门槛（镰 / 匕首 / 剑；镰刀 `kama` 技术可走但不在名单）
- 溅射强化：必须自带生物 AOE（劈刀 / 镰 / 剑 / `kama`；按 m01984 的重武器口径实际只落劈刀与镰）
- 破防重击：`ATTACK_SPEED ≤ 1.0`（大锤 / 劈刀 / 板斧；矿锤 / 短柄斧技术可走但不在名单）
- 处刑：`0.8 ≤ ATTACK_SPEED ≤ 1.0` 且 `!isProjectile`（短柄斧 0.9；剑 1.6 太快不适用）
- 投掷穿刺：仅 `context.isProjectile()`（标枪）
- 装填齐射：需 `tconstruct:crossbow_ammo` 标签（弩）

**第 3 层 · 材料层唯一性（见 3.7）**

- 一把武器上若同时出现两种技能载体材料（劈刀与锤各有不止一个 `head` 类部件）, 两个技能一律失效 —— 正常配装不会触发, 但必须写进代码, 不能只靠玩家自觉

### 未采用的两个旧方案（留档以免重复研究）

- **节奏爆发（Momentum）**：击杀叠层 + 伤害 + 攻速。与 `killing_rhythm` 的触发量/维持方式完全重叠, 且攻速 ×1.50 会让 `ToolAttackUtil` 的无敌帧对齐失效、刷怪塔无限层叠 ⇒ 不新增
- **纯数值路线**：只堆 `attack_damage` 到 86 需约 29 级 `heavy_edge` ⇒ 单击 60, 秒杀一切非 Boss ⇒ 只保留 2 级作基线

### 3.3 七个载体材料的设计位（推荐）

**统一规则**

- **只给 `head` 一个属性组**（不调 `handle()` / `binding()` / `limb()` / `grip()` / `plating*()`）
  - 依据：`TinkerToolParts` 里 `pick_head` / `hammer_head` / `small_axe_head` / `broad_axe_head` / `small_blade` / `broad_blade` / `adze_head` / `large_plate` **全部**是 `HeadMaterialStats.ID`；`tool_handle` / `tough_handle` 才是 `HandleMaterialStats.ID`
  - 依据：`TinkerStationPartSwapping` 用 `registry.getMaterialStats(material, part.getStatType()).isPresent()` 过滤材料 ⇒ **没有 `handle` 属性的材料做不出手柄, 没有 `binding` 属性的材料做不出绑定**
  - 收益：技能只能通过「刃 / 锤头」进入工具, 且结构上做不出弓臂（`limb`）、弓把（`grip`）、盔甲（`plating`）⇒ 不污染四级弓曲线与装备线
- `head` 的 `melee_attack` 分两档：**单发型载体取 6.4~6.5**（与耐热金属同级）⇒ 剑裸值 ≈ **25.0**, 第二章的倍率直接可用；**多段型载体（钨钢）取 1.9** ⇒ 剑裸值 ≈ **16.3**, 配套技能二的 ×5.20 五段追加, 结果仍是 85.8（单击只有精准剑的约三分之一, 但每击跳 5 个数字）。理由：多段型若也用 6.5, `25.0 × 5.20 = 130` 会直接冲破锚点
- 差异只放在**耐久 / 挖掘速度 / 攻速**三项, 作为流派代价；**挖掘速度一律压低**, 这样它天然是「武器材」
- **唯一的例外是弓臂载体**：以太只给 `limb`（不给人任何近战组）, 因为它服务的是弩的「装填齐射」, 必须挂在 `tconstruct:ranged` 组才能进弓臂；`limb` 做不出刃/锤头, 结构上不会污染近战路线
- 每个材料**只挂一个技能**, 等级由该流派需要决定

**七个设计位**

**近战五件（只给 `head`）**

- **铬**（精准突击）：`head(900, 6.4, 6.0, "minecraft:diamond")` ⇒ 耐久低、攻速高；采掘 6.0, 明确是武器材
- **钨钢**（回声连斩）：`head(1300, **1.9**, 5.5, "minecraft:netherite")` ⇒ 耐久最高、单击最低、攻速慢、采掘最差；单击低是**故意的** —— 它的强度全在 ×5.20 的五段追加里（见第二章技能二）
- **红钕**（溅射强化）：`head(1000, 6.4, 6.5, "minecraft:diamond")` ⇒ 各项平庸, 纯技能载体
- **铂**（破防重击）：`head(1200, 6.5, 5.0, "minecraft:netherite")` ⇒ 最慢、采掘最差, 换最高单击
- **钒**（处刑）：`head(1100, 6.5, 5.5, "minecraft:diamond")` ⇒ 耐久中等、采掘中下；服务短柄斧的 0.9 攻速

**远程两件**

- **钛**（投掷穿刺）：`head(1050, 6.5, 5.0, "minecraft:diamond")` ⇒ 只给 `head`, 做标枪的刃（标枪的弓臂与弓把另配紫金）
- **以太**（装填齐射）：`limb(0.15, 0.35, 900, 0.55)` + `ranged` 组挂 `cmi:volley 1` ⇒ 高装填速度、中箭速；V = 1.55、D = 1.70 ⇒ 单箭 10、drawtime 12t、周期 15t ⇒ 1.33 发/秒, 裸 39.9、技能后 **83.8**（备选；追求更高单发就用紫金臂 ⇒ 单箭 13、裸 41.0、技能后 **86.1**）

### 3.4 注册通道（两条都已在工程内）

- **熔点**：一律 `CmiMetal.getMetal(name).getMeltingPoint()`, 不要硬编码（`metals` 表已登记 61 条）
- **合成 / 修复配方**：`setCraftOrRepairRecipe(b => b.input("#forge:ingots/chromium"))`；只有板或齿轮的金属（`platinum` / `tungsten_steel` / `titanium_alloy`）改用 `#forge:plates/...` 或 `#forge:gears/...`
- **熔炼**：`melting(b => b.fluid("cmi:molten_x").amount(90).temperature(getMeltingPoint("x")).material("cmi:x"))`；已有 `tconstruct:molten_chromium` 与 `cmi:molten_scarlet_neodymium`, 其余按 `cmi:molten_<name>` 新建, 或退化成「只有材料配方、没有熔融配方」
- **客户端颜色**：`kubejs/assets/cmi/tinkering/materials/<id>.json`（现已有 `amethyst` / `rope` / `rubberwood` 三个同款）
- **单材料成本** ≈ 40~60 行, 七个材料合计 ≈ 280~420 行（通道 A 更少）

### 3.5 四条纪律

- **只给 `head`, 绝不给 `handle` / `binding`**：给了柄就等于给「同一把武器第二个技能入口」；劈刀与锤的 `large_plate` 也是 `head` 类, 所以这一条不能省, 并配 3.7 的互斥兜底
- **不给近战载体材料 `limb` / `grip`**：一旦给了, 等于给弓新增一级弓臂材料, 四级弓曲线立刻失效；唯一例外是以太（只给 `limb`、服务弩）, 它做不出刃与锤头, 不会反向污染近战
- **裸值不得超过既有 tier4**：载体材料的职责是「带技能」, 不是「更强」；`head` 攻击一律对齐 25.0
- **获取链卡进度**：熔点 1700 K 以上的（铬 / 铂 / 钨钢）排在紫金之后；红钕（1024 K）可提前到 tier3 段, 作为「早一步拿到技能、数值低一档」的入口

### 3.6 新注册相对沿用现成材料的三点收益

- 解开「暗影钢必须让出 `shadow 1`」的取舍：回声连斩挂到钨钢上, 暗影钢保持原状
- 材料名即流派名, 玩家看材料就知道走哪条路, 比靠口头说明或 tooltip 更直接
- 载体材料只给 `head`, 结构上不会长出新弓臂、新弓把或新盔甲, 也做不出手柄与绑定

### 3.7 材料层互斥与「武器材 / 工具材」分流

**问题**：TCon 的材料 trait 按 **stat 组**分发（`MaterialRegistry` 只有四个组：`melee_harvest` = head + handle + binding、`ranged`、`armor`、`ammo`）, 而 `head` 组同时服务刃、锤头、镐头与 `large_plate`。所以「只给 `head`」并不能自动区分「武器」与「工具」, 也挡不住「劈刀用两种技能材做出两个技能」。

**三族材料**

- **武器材（Weapon-grade）**：铬 / 钨钢 / 红钕 / 铂 / 钒 / 钛（前四近战, 后二分别服务处刑与标枪）
  - 只给 `head`；`miningSpeed` 压到 **5.0~6.5**；挂战斗技能
  - 材料标签进 `data/tconstruct/tinkering/tags/materials/melee_harvest/melee.json`
- **工具材（Tool-grade）**：建议从钛 `titanium` / 钒 `vanadium` / 淤钢 `siltsteel` / 铝合金 `aluminum_alloy` 中选 3 个
  - 给 `head` + `handle` + `binding`；`miningSpeed` **8.0~9.0**、耐久 1500~2000、`melee_attack` 4.0~4.5（打不动怪）
  - 挂采集向 trait（`tconstruct:haste`、`nebula_tinker:petramor`, 或新建 `cmi:deep_dig`）, **不挂战斗技能**
  - 材料标签进 `.../melee_harvest/harvest.json`
- **通用材（现有 tier2~4）**：保持现状, 全套属性、无战斗技能、无采掘专精, 标签留在 `general.json`

**互斥怎么在材料层就成立**

- 第 1 道（结构）：技能材只给 `head` ⇒ 无法通过柄 / 绑定带入第二个技能
- 第 2 道（唯一性）：技能 hook 入口检查工具上的材料与技能 —— 若同时存在**另一种**技能载体材料（或另一种技能 modifier 等级 > 0）, 本技能直接返回原值；两者互斥等于双输, 玩家不会这么配
- 第 3 道（标签）：战斗技能只在 `#tconstruct:modifiable/melee/weapon` 生效, 采集技能只在 `#tconstruct:modifiable/harvest` 生效 ⇒ 同一份材料做出来的武器与工具, 能力不会串
- 一句话：**材料决定流派, 标签决定生效面, 互斥检查兜底**

**成本**

- 六个武器材：40~60 行 × 6 ≈ 240~360 行；弓臂载体（以太）另计 20 行
- 三个工具材：40~60 行 × 3 ≈ 120~180 行
- 材料标签三条 JSON：各 1 行 `values` 追加
- 互斥检查：每个技能入口约 5 行（五个近战技能 ≈ 25 行, 另加两个远程技能判定）

## 四、数值简析

### 4.1 材料层（免费, 十件武器对齐）

**单体档（目标 73~99）**

- 长弓 收束齐射 / 贴身散射：**85.7**（L4 紫金臂 ×2）
- 弩 装填齐射：裸 41.0 → **86.1**（紫金臂 ×1, 单弓臂）
- 标枪 投掷穿刺：裸 45.8/发 → **84.7**
- 剑 精准突击 **85.0** / 回声连斩 **85.8**（两条二选一）
- 匕首 回声连斩 **85.8**
- 短柄斧 处刑 **82.0**

**AOE 档（目标 3 目标 85.7）**

- 劈刀 溅射强化：单体 57.1 / 3 目标 **139.4**
- 镰 精准突击：单体 27.5 / 3 目标 **82.5**（`circle_melee` 逐目标结算）；回声连斩 25.5 / 76.5

**团队档（目标 55~70）**

- 板斧 破防重击 **67.9**、大锤 **57.2**、劈刀（备选）**61.3**

**比值**：单体档 / 长弓 L4 = **0.96~1.00** ⇒ 同档；AOE 档 3 目标 = 0.96~1.63；团队档 = 0.67~0.79, 缺口由「破防让全队受到的伤害 +20%」兑换。

### 4.2 投入层（上限对齐）

- 长弓：converge 4（只改距离）+ 光辉石箭 ⇒ **124.3**
- 弩：`volley_core` + `quick_load` ⇒ **106.7**
- 标枪：`returning` + `pierce_lens` ⇒ **94**
- 近战：剑 精准 **97.8** / 回声 **112.2**；劈刀 溅射 **70.6**（3 目标 151.2）；板斧 破防 **67.9**（配 `sunder 2` 后破防 +40%）
- 比值 **0.76~0.90** ⇒ 近战上限仍不超弓, 且弓的上限要每发付费

### 4.3 距离分层（四种远程的满伤圈各不相同）

- 长弓：3 箭水平 ±10° ⇒ 满伤圈 **1.70 格**；converge 4 ⇒ **8.60 格**
- 弩：同样 ±10° 水平扇形 ⇒ 满伤圈也是 **1.70 格**；`converge` 对它无效（不走 `releaseUsing`, 走 `fireCrossbow` 的 rotate）
- 标枪：单发无散布 ⇒ **射程即有效射程**, 代价是每次投掷要先 18t 蓄力
- 近战：判定距离 **3.0 格**

分层：

- **0~1.7 格**：长弓 85.7 / 弩 86.1 / 标枪 84.7 / 近战 82.0~112.2 ⇒ 近战与标枪略优
- **1.7~3.0 格**：长弓与弩都只中 1 支 ⇒ **28.6**；标枪 84.7、近战 82~112 ⇒ 反超 2.9~3.9 倍
- **3.0~8.6 格**：只有远程 —— 长弓（converge 4）85.7、弩 86.1、标枪 84.7、裸长弓 28.6
- **8.6 格以上**：长弓 converge 4 仍有 85.7（约到 15 格受箭速衰减）；弩与标枪不受散布限制

### 4.4 群体分层

- 长弓 A（收束齐射）：恒定 ≤ **85.7**（3 箭钳死）
- 长弓 B（贴身散射）：1 / 2 / 3 / 6 目标 = **85.7 / 145.7 / 205.7 / 205.7**（装 `scatter_lens` 后 6 目标 **265.7**）
- 弩：箭数 = 装填数 ×（1 + 2×multishot）⇒ 3 箭最多覆盖 3 个目标, **86.1 / 171.2 / 258.3**（需目标落在三条射线上）
- 标枪（贯穿）：1 / 2 / 3 目标 = **84.7 / 112.9 / 139.7**
- 劈刀（溅射）：1 / 2 / 3 / 6 目标 = **57.1 / 98.3 / 139.4 / 262.1**
- 镰（精准突击）：1 / 2 / 3 目标 = **27.5 / 55.0 / 82.5**

结论：3 目标内长弓 B 的 205.7 最高, 但只在 1.7 格内；中距离群伤由劈刀（139.4）与标枪（139.7）接住；6 目标劈刀 262.1 与长弓 B 的 265.7 持平 ⇒ 群体不再由某一侧独占。

### 4.5 四条刻意保留的不对称

- **距离**：1.7 格之外长弓与弩掉到 28.6, 而标枪与近战仍满伤 ⇒ 四种近身武器的距离窗互不重叠
- **群体**：长弓 B 只能在 1.7 格内群伤, 劈刀与标枪能在中距离群伤
- **成本形态**：近战与标枪（`returning`）的上限永久有效, 长弓的上限每发付费（光辉石箭）
- **时间窗**：标枪 18t、弩 19t、长弓 14t —— 前两者是「打一发是一发」, 长弓是连续输出

### 4.6 风险提示（落地时必须处理）

- floor 与低 tier 错配：floor 取 **8**（取 10 会让匕首到 104、超锚点 21%）；tier1 木剑单击 4 装技能仍会白拿 40 追加 ⇒ 建议 `max(比例 × 伤害, min(8, 0.3 × 伤害))`
- 与 `acupoint` / `causal_truncation` 的叠乘必须在 `onDamageDealt` 用 `isDirectDamage` 在代码层拦, 不能只写文档
- 溅射在劈刀上 6 目标 262.1（与长弓 B 的 265.7 持平）；风险在于日后把红钕挂到高攻速武器上（剑开溅射会到 390）⇒ 四道闸：目标数封顶 8、光爆段不吃按目标数追加、`quake_core` 波及 ≥5 不触发、类型闸门只让自带生物 AOE 的武器生效
- 无限槽位下 130 上限是设计意图而非机制保证（软约束：材料定价 / 同类互斥 / 数值饱和）
- 精准突击的期望随判定达成率线性变化（100% / 80% / 60% ⇒ 85.0 / 73.0 / 61.0）, 验收必须记录达成率, 不能只测一次命中
- 劈刀与锤有两个 `head` 类部件（`broad_blade` + `large_plate` / `hammer_head` + `large_plate`）, 若玩家用两种技能材配装, 按 3.7 第 2 道两者都失效 —— tooltip 要写明原因, 否则会被当成 bug
- **弩的每支箭无条件暴击**（`arrow.m_36762_(true)`）⇒ 期望 ×1.25, 验收必须分「不含暴击」与「含暴击」两列, 否则弩会被误判为超模
- **标枪投掷走 `performAttack`** ⇒ 触发 `onAfterMeleeHit`；五个技能都必须用 `context.isProjectile()` 隔离, 否则投掷会吃近战技能（尤其精准突击与回声连斩）
- 处刑的 `×(0.9 / attackSpeed)` 在攻速 > 1.0 时小于 1 ⇒ 过滤窗必须严格写成 `0.8 ≤ ATTACK_SPEED ≤ 1.0`, 否则剑（1.45）会白拿 62% 追加
（本文为流派设计, 数值均为推算值；实现清单、代码依据与待裁定项见 [TCon武器平衡分析案.md](TCon武器平衡分析案.md)。）
