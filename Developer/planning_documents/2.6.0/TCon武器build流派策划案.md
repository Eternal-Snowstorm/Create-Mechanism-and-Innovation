# TCon 武器 build 流派策划案

> 配套文档：[TCon武器平衡分析案.md](TCon武器平衡分析案.md)（本文只写「怎么配、配出来什么」，推导与代码依据见分析案）。
> 本文为设计方案，未对整合包做任何修改。

---

## 〇、设计前提

**五条铁律**

- **强度锚点**：毕业弓（紫金弓臂 ×2 + 3 箭齐射）贴脸 **85.7 DPS**；毕业近战四个流派各落 **85~88 DPS**。
- **技能绑材料，不绑槽位**。槽位可无限购买（`tconstruct:writable` / `draconic` 无等级上限），若技能占槽则玩家会四个全装、倍率互乘；材料结构上不可通吃（一把剑只有一个主刃），是唯一能保证「同一时刻只有一条流派生效」的约束。
- **三层强度结构**
  - 第 1 层 **材料层**：材料固有 trait，免费不占槽 → 目标 85~88（锚点）
  - 第 2 层 **投入层**：针对性强化件，成本 = 材料 + 时间 → 目标 110~130（设计上限）
  - 第 3 层 **消耗层**：每发成本 → **仅弓有**（光辉石箭），近战没有
- **互斥必须靠机制语义，不能靠槽位占用**。弓的两条流派在代码层读等级互斥。
- **材料池可扩展**。技能载体不必局限于现有材料：金属表里还有 11 个「物品已存在、熔点已登记、材料未注册」的对象，可现注册为流派专属载体（见第三章）。

**两条成本形态差异（刻意保留）**

- 弓的上限 124.3 是「每发付费」；近战的上限 110~130 是「装完永久有效」。
- 因此近战不设消耗层，但上限卡 130 以内，不许出现「永久有效的 150」。

## 一、弓侧：两条互斥流派

### 流派 A｜收束齐射（单体远射型，首推）

**定位**：把「3 箭齐射」的空间分散问题用 converge 收束，换取远距离满伤。

- **载体**：长弓 / 弩 + `nebula_tinker:converge`
- **材料路线**（四级递增）
  - L1 工业铁弓臂 ×2：单箭 8，射速 1.333，贴脸 32.0
  - L2 不锈钢弓臂 ×2：单箭 10，射速 1.333，贴脸 40.0
  - L3 戴斯弓臂 ×2：单箭 14，射速 1.429，贴脸 60.0
  - L4 紫金弓臂 ×2：单箭 20，射速 1.429，贴脸 **85.7**
- **核心件**：converge **4 级**（`upgrades 1`，材料 `thermal:rf_coil` + `functionalstorage:redstone_upgrade`）
  - 满伤圈（三箭全中）随等级：0 级 1.70 / 1 级 2.13 / 2 级 2.85 / 3 级 4.29 / **4 级 8.60 格**
  - 5 级及以上是完全收敛（三箭轨迹重合、满伤圈不受几何限制）⇒ **配方上限锁 4 级**，否则等于取消距离分层
- **配套投入**
  - `accuracy` 拉满（`inaccuracy = 3.0 × (1/accuracy − 1)`，1.0 时零随机散布）
  - `tconstruct:lightweight`（每级 `attack_speed` / `draw_speed` / `velocity` 各 +3~8%）—— 只提射速与箭速，不改单箭
  - 消耗层：光辉石箭头（`refined_radiance` 的 `ammo` 组已是 `keen 2`，每级 +0.5 projectile_damage）⇒ 单箭 20 → **29**
- **互斥**：`cmi:point_blank` 在代码层读 converge 等级 > 0 即失效
- **生态位**：3 格以外的所有场合；对 Boss 大碰撞箱可延伸到 17~29 格

### 流派 B｜贴身散射（6 格内群伤型，与齐射互斥）

**定位**：不追求射程，把 3 箭的落点变成 3 次小范围爆炸，专打贴身小怪群。

- **载体**：长弓 / 弩 + `cmi:point_blank` 1~3 + `cmi:scatter_lens`
- **核心件**
  - `cmi:point_blank`（`upgrades 1`，`level 1~3`）：命中点距射手 **≤ 6 格** 时，对命中点 **1.5 格内最多 2 个**其他生物各受 **40% / 55% / 70%** × 该次箭直接伤害；不暴击、不触发技能层数、同 tick 同目标只吃一次箭爆
  - `cmi:scatter_lens`（`upgrades 1`，`level 1`）：箭爆波及目标数 2 → **3**（需 `point_blank` 前置）
- **配套投入**
  - `tconstruct:lightweight 2`：射速 1.429 → **1.538**（横向提速，允许）
  - 光辉石箭头：单箭 20 → 29
- **互斥**：与 converge 互斥（同占 `upgrades 1` 只是心理提示，真正的约束是 `point_blank` 各 hook 入口读 converge 等级后直接返回原值）
- **生态位**：6 格内的刷怪塔、小怪群、要塞走廊；与近战溅射强化抢同一块地盘

### 弓侧的「不构成流派」路线（留档）

- **疾速薄射**：`featherweight 2` + 不锈钢弓臂 ×2 ⇒ 射速换伤害，46.2 DPS，天然低于锚点 ⇒ 自我降级换手感，**不需平衡干预**
- **虚空蚀射**：暗影钢 `ranged shadow 2` 每箭 +3 真实伤害并清 i-frame，3 箭 +9 ≈ +10%，落在锚点 ±15% 容差内 ⇒ 视为材料固有溢价，**不做独立流派**（做流派需另配强化件，工作量过大）
- **弹种特化**：本质是流派 A 的消耗层通道，不单列

## 二、近战侧：四个材料专有技能

### 共同地基：`cmi:heavy_edge`

- **是什么**：`melee_harvest` 材料 trait，`stat_boost attack_damage` 每级 **+1.5**（add），上限 2 级
- **为什么需要**：tier4 剑裸值 19.4，走满倍率只到 74，差锚点 14%
- **怎么挂**：tier4（紫金 / 戴斯 / 耐热金属 / 四个新载体材料）挂 **2 级**（+3.0）；tier3（黄铜 / 铸铁 / 暗影钢 / 阿迪特 / 不锈钢 / 光辉石）挂 **1 级**（+1.5）；tier2 不挂
- **纪律**：不许靠加它解决平衡（到 86 需约 29 级，单击 60 会让僵尸/末影人一刀必死）；它的职责只是让倍率落在「8~10 层 / 4~5 段」这种看得见的区间

**tier4 各武器裸 DPS（含 heavy_edge 2 级）**

- 剑 25.0（单击 17.5 / 攻速 1.45）
- 匕首 17.4（9.4 / 1.85）
- 劈刀 16.8（19.8 / 0.85）
- 短柄斧 14.9（16.6 / 0.90）
- 矿锤 14.4（16.9 / 0.85）
- 战斧 14.3（23.8 / 0.60）
- 大锤 14.3（19.1 / 0.75）
- 战牌 11.8（9.8 / 1.20）
- 镰刀 kama 11.2（7.0 / 1.60）
- 镰 scythe 8.1（11.6 / 0.70）

### 技能一｜精准连击（Precision Combo）

- **载体材料**：本命 **铬 `chromium`**（tier4，待注册）；现成可用 **戴斯**
- **适配武器**：剑、匕首、镰刀 kama；**类型过滤 `ATTACK_SPEED ≥ 1.2`**
- **判定量 = 时机，不是目标**
  - 记上次命中 `t_prev`，本次 `t_now`，`gap = t_now − t_prev`
  - 武器冷却 `C = ceil(20 / attackSpeed)`（取玩家当前 `ATTACK_SPEED` 属性实时算）
  - 判定窗 `W = [C, C + J]`，容差 `J = max(3, ceil(C × 0.25))`
  - `gap ∈ W` ⇒ 层数 +1（上限 **10**）；`gap < C` 或 `gap > C+J` ⇒ 层数清零
- **效果**：每层伤害 **+6% × 等级**（材料挂 **4 级** ⇒ 每层 +24%），满 10 层 **×3.40**
- **强化件**
  - `cmi:tempo_window`（`upgrades 1`，`level 1~2`）：容差 `J` 每级 +1 tick
  - `cmi:chain_finisher`（`abilities 1`，`level 1`）：满层时再 +30%
  - 原生 `tconstruct:swiftstrike`（提高攻速 ⇒ 缩短 C，让窗口更早到）
- **禁区**
  - 与 `nebula_tinker:killing_rhythm` 叠乘会让剑到 160+
  - 追加段不得触发 `acupoint` 血量斩（满层一击会直接触发）
- **手感特征**：快武器爬坡快（匕首 5.5s / 剑 7.0s / 战斧 17s）⇒ 这是「快武器专精」的真实机制来源

### 技能二｜回声连斩（Echo Slash）

- **载体材料**：本命 **钨钢 `tungsten_steel`**（tier4，待注册）；现成可用 **暗影钢**（走 `melee_harvest` 组时需替换其 `shadow 1`，`ranged` 的 `shadow 2` 保留 —— 换钨钢后这个取舍消失）
- **适配武器**：剑、劈刀、战斧；近战武器且非纯采集工具
- **效果**：命中后按 tick 追加 5 段
  - 延迟 4 / 8 / 12 / 16 / 20 tick
  - 每段比例 80% / 80% / 80% / 80% / 100%（合计 **+420% ⇒ ×5.20**）
  - 每段取 `max(比例 × 本次伤害, 10)`（floor 10：4 会被护甲吃掉，20 会让匕首白拿 100%）
  - 走 `ToolAttackUtil.hurtNoInvulnerableTime`：不产生击退、不暴击、不触发其他技能层数、不触发血量斩
- **强化件**
  - `cmi:echo_lance`（`abilities 1`，`level 1~2`）：每级 +1 段 ⇒ 7 段约 ×6.8
  - `cmi:echo_delay`（`upgrades 1`）：段间隔 −1 tick
  - 原生 `nebula_tinker:death_echo`（暴击系）
- **禁区**：`acupoint`（20 tick 内从满血到 1 血且不可中断）
- **手感特征**：单击高则绝对值高，是「重武器」的流派；暗影钢定位「tier3 强度但早一步拿到技能」，代价是耐久 620 与升级空间小

### 技能三｜溅射强化（Glow Splash）

- **载体材料**：本命 **红钕 `scarlet_neodymium`**（tier4，待注册）；现成可用 **紫金**
- **适配武器**：**只给已有生物 AOE 的武器**（剑 `sweep_melee`、劈刀 `sweep_melee 2.0`、镰 `circle_melee`、镰刀 `circle_melee`）
  - 理由：TCon 已有 4 把生物 AOE 武器，再给无 AOE 的锤斧加溅射等于改变设计意图（锤斧的 AOE 是方块 AOE）
- **效果**：命中后 6 tick 结算「光爆」
  - 半径 **2.5 格**内最多 **8 个**其他生物各受 **240%**（走 `attackEntitySecondary`，无击退）
  - 主目标额外受 **240% 回灌**
  - 每波及 1 个目标主目标再 +5%（上限 +20%）
  - 光爆不触发其他技能层数；自带 AOE 照常结算，光爆是额外一层
- **强化件**
  - `tconstruct:expanded`（`abilities 1`，原生）：每级 +1 范围 —— 两条 WeaponAttack 都读 volatile EXPANDED，**对无 AOE 模块的武器无副作用**，是「只给已有 AOE 武器」最省事的实现
  - `cmi:splash_focus`（`upgrades 1`，`level 1~2`）：回灌 +40%/级
  - `cmi:quake_core`（`abilities 1`）：波及 ≥3 目标时触发 100% 震荡
  - 原生 `tconstruct:sweeping_edge`（仅剑/劈刀；未装时横扫只有 1.0 点）
- **注意**：`sweep_melee` 直接 `aoeTarget.hurt()` 不吃近战 hook，`circle_melee` 走 `performAttack` 全吃 hook ⇒ 两套模块的数值表现不同，验收要分开测
- **生态位**：3~6 目标的小怪群，这是近战唯一能稳定超过弓的场景

### 技能四｜破防重击（Guard Break）

- **载体材料**：本命 **铂 `platinum`**（tier4，待注册）；现成可用 **耐热金属**
- **适配武器**：大锤、矿锤、战斧、短柄斧；**类型过滤 `ATTACK_SPEED ≤ 1.0`**
- **效果**
  - 计数 key =（玩家, 目标），**每第 2 次**命中追加 **500%**（`hurtNoInvulnerableTime` + `damageSources().generic()` 穿甲）
  - 同时给目标「破防」：受伤 **×1.20**，100 tick，只刷新不叠加
  - 追加段不暴击、不触发其他技能层数
  - 平均乘数 **×3.50**
- **强化件**
  - `cmi:sunder`（`upgrades 1`，`level 1~2`）：破防受伤 +10%/级（最高 40%）
  - `cmi:hammerfall`（`abilities 1`）：每次命中都触发，但追加降到 200%（锤专精）
  - 原生 `tconstruct:smite`
- **为什么第 2 次不是第 3 次**：第 3 次需单次 1000%（单击追加 170，像 Bug）；提高频率、降低单次更容易读也更好平衡
- **生态位**：Boss 与高血量目标；团队收益最高（破防是全队共享的受伤加成）

### 四个技能的类型过滤（必须写进代码）

- 精准连击：`ATTACK_SPEED ≥ 1.2`
- 回声连斩：近战武器，且不是纯采集工具
- 溅射强化：任意近战（建议只挂紫金刃）
- 破防重击：`ATTACK_SPEED ≤ 1.0`

### 未采用的两个旧方案（留档以免重复研究）

- **节奏爆发（Momentum）**：击杀叠层 + 伤害 + 攻速。与 `killing_rhythm` 的触发量/维持方式完全重叠，且攻速 ×1.50 会让 `ToolAttackUtil` 的无敌帧对齐失效、刷怪塔无限层叠 ⇒ 不新增
- **纯数值路线**：只堆 `attack_damage` 到 86 需约 29 级 `heavy_edge` ⇒ 单击 60，秒杀一切非 Boss ⇒ 只保留 2 级作基线

### 武器—流派配对（推荐表）

- 剑 → 精准连击（本命，爬坡 7s）/ 回声连斩 / 溅射强化 / 破防重击 —— 四技能都能到 85 档，剑是最百搭的载体
- 匕首 → 精准连击（爬坡 5.5s，最快）/ 回声连斩（走 floor 托底）
- 劈刀 → 回声连斩（本命）/ 溅射强化（自带 `sweep_melee 2.0`）
- 战斧 → 回声连斩 / 破防重击（群体向）
- 短柄斧 → 破防重击 / 回声连斩
- 大锤 → 破防重击（本命）
- 矿锤 → 破防重击（本命）
- 镰刀 kama → 精准连击（自带 `circle_melee`，溅射强化会自动关闭）
- 战牌 battlesign → 破防重击（功能档，不追求 86）
- 镰 scythe → 按裁定视为**工具**，不参与武器平衡目标；其溅射档（单体 27.5 / 3 目标 68）不作为验收项

## 三、载体材料与材料池

> 前提修正：技能**不必**绑在现有四个材料上。整合包金属表里另有 11 个「金属物品已存在、熔点已登记、尚未做成匠魂材料」的对象，可直接注册为流派专属载体。

### 3.1 材料池三档

- **档 1 · 模组已提供（40 个，不建议动）**
  - 匠魂本体 32 个、热力工匠 8 个；它们的材料定义属于别的模组，再次注册等于覆盖，会连带影响整合包既有配方
- **档 2 · 整合包自定义、已注册（10 个）**
  - `industrial_iron` / `andesite_alloy` / `cast_iron` / `shadow_steel` / `refined_radiance` / `ardite` / `stainless_steel` / `desh` / `ostrom` / `calorite`
  - 用途：现有 build 的默认载体，数值已与四级弓曲线对齐
  - 另有 `brass`（覆盖本体材料）与三个非金属 `rope` / `rubberwood` / `amethyst`
- **档 3 · 整合包自定义、金属已登记但材料未注册（11 个）** ⇒ **新载体材料的首选池**
  - 判定口径：`InitGlobal.js` 的 `metals` 表里 `n: "c"` 的条目，且 `TConMaterial.js` 里没有同名材料定义

### 3.2 十一个候选（熔点取自 `CmiMetal`，形态取自现有物料引用）

- **铬 `chromium`** 1907 K，锭 —— 精密、低摩擦，**精准连击**首选
- **钨钢 `tungsten_steel`** 2524 K，板 / 齿轮 —— 高密度，**回声连斩**首选
- **铂 `platinum`** 1768 K，板 —— 高密度贵金属，**破防重击**首选
- **红钕 `scarlet_neodymium`** 1024 K，锭 —— 磁能爆裂，**溅射强化**首选
- 备选：钒 `vanadium` 1910 K（板/锭）、钛 `titanium` 1668 K（锭/板/齿轮）、钛合金 `titanium_alloy` 1634 K（板/齿轮）、淤钢 `siltsteel` 1386 K（锭）、蓝钕 `azure_neodymium` 1024 K（锭）、以太 `etrium` 1486 K（锭/板/块）、铝合金 `aluminum_alloy` 592 K（板/锭）

### 3.3 四个载体材料的设计位（推荐）

**统一规则**

- **只给 `head` 与 `handle` 两个属性组**，不给 `limb` / `grip` / `plating` ⇒ 结构上做不出弓臂、弓把与盔甲 ⇒ 天然不污染四级弓曲线与装备线
- `head` 的 `melee_attack` 取 **6.4~6.5**、`handle` 的 `melee_damage` 取 **0.30**（与耐热金属同级）⇒ 剑裸值仍 ≈ **25.0**，第二章的倍率全部不用重算
- 差异只放在**耐久 / 挖掘速度 / 攻速**三项，作为流派代价
- 每个材料**只挂一个技能**，等级由该流派需要决定

**四个设计位**

- **铬**（精准连击）：`head(900, 6.4, 7.5, "minecraft:diamond")`、`handle(0.15, 0.30, 0.20, 0.10)` ⇒ 耐久低、攻速高（利于叠层，代价是单次弱）
- **钨钢**（回声连斩）：`head(1300, 6.5, 6.0, "minecraft:netherite")`、`handle(0.35, 0.30, -0.10, 0.20)` ⇒ 耐久高、攻速慢、挖掘差
- **红钕**（溅射强化）：`head(1000, 6.4, 7.0, "minecraft:diamond")`、`handle(0.20, 0.30, 0.00, 0.15)` ⇒ 各项平庸，纯技能载体
- **铂**（破防重击）：`head(1200, 6.5, 6.5, "minecraft:netherite")`、`handle(0.30, 0.30, -0.15, 0.20)` ⇒ 最慢，换最高单击

### 3.4 注册通道（两条都已在工程内）

- **通道 A（推荐，最短）**：`kubejs/server_scripts/utils/TConMaterialGenerator.js` 的 `TConMaterial(event, name, handler)` —— 一次调用自动写出 `definition` / `stats` / `traits` / `recipes( material、material_fluid、material_melting )` 六类 JSON。该文件当前带 `// ignored: true`，启用后在各数据包事件里调用即可
- **通道 B（现有风格）**：`kubejs/server_scripts/data/tconstruct/TConMaterial.js` 的 `new TConMaterial("x").definition().stats().traits().melting().build()`，与现有 14 个材料同一套写法
- **熔点**：一律 `CmiMetal.getMetal(name).getMeltingPoint()`，不要硬编码（`metals` 表已登记 61 条）
- **合成 / 修复配方**：`setCraftOrRepairRecipe(b => b.input("#forge:ingots/chromium"))`；只有板或齿轮的金属（`platinum` / `tungsten_steel` / `titanium_alloy`）改用 `#forge:plates/...` 或 `#forge:gears/...`
- **熔炼**：`melting(b => b.fluid("cmi:molten_x").amount(90).temperature(getMeltingPoint("x")).material("cmi:x"))`；已有 `tconstruct:molten_chromium` 与 `cmi:molten_scarlet_neodymium`，其余按 `cmi:molten_<name>` 新建，或退化成「只有材料配方、没有熔融配方」
- **客户端颜色**：`kubejs/assets/cmi/tinkering/materials/<id>.json`（现已有 `amethyst` / `rope` / `rubberwood` 三个同款）
- **单材料成本** ≈ 40~60 行，四个材料合计 ≈ 200~240 行（通道 A 更少）

### 3.5 三条纪律

- **不给载体材料 `limb` / `grip`**：一旦给了，等于给弓新增一级弓臂材料，四级弓曲线立刻失效
- **裸值不得超过既有 tier4**：载体材料的职责是「带技能」，不是「更强」；`head` 攻击一律对齐 25.0
- **获取链卡进度**：熔点 1700 K 以上的（铬 / 铂 / 钨钢）排在紫金之后；红钕（1024 K）可提前到 tier3 段，作为「早一步拿到技能、数值低一档」的入口

### 3.6 新注册相对沿用现成材料的三点收益

- 解开「暗影钢必须让出 `shadow 1`」的取舍：回声连斩挂到钨钢上，暗影钢保持原状
- 材料名即流派名，玩家看材料就知道走哪条路，比靠口头说明或 tooltip 更直接
- 载体材料只给 `head` / `handle`，结构上不会长出新弓臂、新弓把或新盔甲

## 四、数值简析

### 4.1 材料层（免费，两侧对齐）

- 弓四级贴脸：**32.0 / 40.0 / 60.0 / 85.7**（远距只中 1 箭时为 10.7 / 13.3 / 20.0 / 28.6）
- 近战四技能（剑为载体）：**85.0 / 85.8 / 85.0 / 87.5**
- 比值：近战 / 弓 L4 = **0.99 ~ 1.02 倍** ⇒ 贴脸同档成立

### 4.2 投入层（上限对齐）

- 弓：converge 4（只改距离）+ 光辉石箭 ⇒ 单体 **124.3**
- 近战：精准 110.5 / 回声 112.2 / 溅射 105.0 / 破防 87.5（破防靠团队）
- 比值：近战 / 弓 = **0.70 ~ 0.90**（破防单体偏低，其价值在破防的团队加成）

### 4.3 距离分层（弓的满伤圈决定一切）

- **0 ~ 1.7 格**：弓 85.7，近战 85~130 ⇒ 近战略优（无散布损失 + AOE）
- **1.7 ~ 3.0 格**：弓只中中央 1 箭 **28.6**，近战 85~130 ⇒ **近战反超 3~4.5 倍**
- **3.0 ~ 8.6 格**：裸弓 28.6；装 converge 4 则 85.7；近战 0（超出 3.0 格判定距离）⇒ 弓独占
- **8.6 格以上**：弓 28.6 → 15，近战 0
- 大碰撞箱 Boss：裸弓满伤圈 3.4~5.7 格、converge 4 到 17~29 格 ⇒ 合理的体型溢价，不额外干预

### 4.4 群体分层

- 弓流派 A：恒定 ≤ 85.7（每发 3 箭钳死，需目标落在三条射线上）
- 弓流派 B：1 / 2 / 3 / 6 目标 = **85.7 / 145.7 / 205.7 / 205.7**（装 `scatter_lens` 后 6 目标 265.7）
- 近战溅射强化：1 / 2 / 3 / 6 目标 = **85.0 / 146.3 / 207.5 / 390.0**
- 结论：3 目标两侧同档（205.7 vs 207.5），**6 目标近战是弓的 1.47 倍** ⇒ 大群 AOE 是近战独占生态位

### 4.5 三条刻意保留的不对称

- **距离**：3.0~8.6 格弓独占 —— 这是远程武器的定义，不是失衡
- **群体**：大群（6+）近战更强 —— 弓被「每发 3 箭」结构钳死，近战 AOE 无上限
- **成本形态**：近战上限永久有效、弓上限每发付费 —— 长时间低强度战斗近战更划算，Boss 战弓更划算

### 4.6 风险提示（落地时必须处理）

- floor 与低 tier 错配：tier1 木剑单击 4 装技能会白拿 37 追加 ⇒ 建议 `max(比例 × 伤害, min(10, 0.3 × 伤害))`
- 与 `acupoint` / `causal_truncation` 的叠乘必须在 `onDamageDealt` 用 `isDirectDamage` 在代码层拦，不能只写文档
- 溅射 6 目标 390 是弓的 1.47 倍，需三道闸：目标数封顶 8、光爆段不吃按目标数追加、`quake_core` 波及 ≥5 不触发
- 无限槽位下 130 上限是设计意图而非机制保证（软约束：材料定价 / 同类互斥 / 数值饱和）
